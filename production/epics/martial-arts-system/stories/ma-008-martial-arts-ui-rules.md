## 目标

定义武学管理界面和战斗招式面板的呈现规则，让玩家能用数字、条件和效果判断招式价值，而不是依赖品质颜色。

## 范围

### 包含
- 武学卡片显示：名称、体系图标、内息消耗、招式威力倍率
- 触发条件和特殊效果直接可见，不折叠
- 所有招式卡片颜色只体现体系，不体现稀有度
- 高级/绝学使用收集进度条或层级标记表现残卷/拓本/完本/真传
- 普通武学显示“已习得”，不显示进度条
- 批注版使用古卷质感、朱砂批注笔迹或独特边框纹路区分
- 战斗面板显示 6 个装备招式 + 心法专属招式
- 支持快速比较时并排展示条件、效果和倍率数值

### 不包含
- 正式 UX 线框、动效和视觉资产 → `/ux-design` / `/asset-spec`
- 战斗 UI 的完整 HUD 和输入实现 → combat-ui
- 实际拖拽代码实现如超出本 story，可在后续 UI story 中承接

## 技术说明

- UI 数据来自 ma-001 ~ ma-007 的查询 DTO，不直接读取 YAML 文件
- 稀有度不得通过绿/蓝/紫/金/红品质颜色表达
- 体系颜色可以使用刚系暖赤金、柔系玄青冷色、巧系烟灰中性
- 条件与效果是玩家决策核心信息，默认展开显示

## 验收标准

- [ ] 武学管理界面加载后，所有招式卡片颜色仅体现刚/柔/巧体系，不体现稀有度等级
- [ ] 高级/绝学招式通过进度条或层级标记传达残卷、拓本、完本、真传状态
- [ ] 普通武学显示“已习得”，不显示进度条
- [ ] 任意武学详情展开后，触发条件和特殊效果直接可见，倍率以数字明确展示
- [ ] 战斗中招式面板显示 6 个装备招式 + 心法专属招式
- [ ] 批注版招式以独特质感或边框纹路区别于普通层级，而不是依赖品质颜色

## QA 测试用例

- **AC-1**：无品质颜色
  - Setup：打开武学管理界面，准备普通、高级、绝学、批注版招式各一项
  - Verify：卡片颜色只随刚/柔/巧体系变化，不随普通/高级/绝学变化
  - Pass condition：看不到绿/蓝/紫/金/红品质色阶表达

- **AC-2**：条件效果直接可见
  - Setup：打开任意武学详情
  - Verify：触发条件、特殊效果、倍率数字默认可见，无需展开二级折叠
  - Pass condition：玩家能在一个详情视图内同时看到条件、效果和倍率

- **AC-3**：战斗面板招式来源
  - Setup：角色装备 6 个基础招式和 1 个含 2 个专属招式的心法
  - Verify：战斗招式面板显示 8 个可选招式，并区分心法专属来源
  - Pass condition：6 个基础槽位与 2 个心法专属招式均可识别
