# 序章一日一夜设计

> **项目**：《风止》  
> **章节**：序章：风止（落尘谷 / 风止山庄）  
> **结构**：一日一夜  
> **状态**：Draft for Review  
> **日期**：2026-06-29  

## 1. 设计目标

序章的核心任务是让玩家先相信“风止山庄是家”，再亲手确认这个家已经不可挽回地失去。

本设计采用“一日一夜”结构：玩家在庄主寿宴前一日经历完整的山庄日常，入夜后去后山崖洞取三年陈药酒，因此错过灭门；次日回庄后通过探索、搜证、误会澄清、共同埋葬和临别传承完成序章收束。

序章不以战斗开场，也不提前污染幸福日常。灭门前的主体验是被保护、被催促、被疼爱、被山庄众人接住；灭门后的主体验才是无力、不理解、自责和被迫成长。

## 2. 核心原则

1. 灭门前不埋明显阴谋感。
   - 师姐采集段发现的是动物足迹，不是外人痕迹。
   - 山庄日常保持明亮、温柔、松弛。
   - 玩家知道这是寿宴前的一天，但角色不知道灾祸将至。

2. 战斗教学后移到灭门后。
   - 灭门前不安排师兄切磋或正式战斗教学。
   - 师兄采买回山后触发误会系统；误会解除后，师兄才教授风止尺法基础。
   - 战斗教学不是快乐切磋，而是临别赠礼：“以后没人护你了，你得会自保。”

3. 师姐是序章情感核心。
   - 师姐负责采药、采矿教学。
   - 师姐解释主角为什么此前没学过采集：主角小时候被保护得太好，师姐怕他受伤，所以一直不肯教；最近主角执拗想学，师姐拗不过才带他上山。
   - 崖洞内每个互动点都勾起与师姐相关的回忆。

4. 主角拖延取酒制造后续自责。
   - 傍晚师姐催主角去崖洞取酒。
   - 主角仗着后山路熟，觉得闭着眼也能走过去，于是继续陷在山庄群像温柔乡里。
   - 入夜后才去取酒，导致夜宿崖洞；这成为玩家事后自责的情绪根。

5. 灭门不是战斗关。
   - 玩家赶回时一切已经结束。
   - 玩法是探索、调查、洞察和确认。
   - 关键情绪不是“我马上复仇”，而是“不可能，为什么？”

## 3. 目标时长

目标可玩时长：70-90 分钟。

首版可制作目标控制在约 70 分钟，通过后续群像对话、可选调查、山庄支线闲话补足到 90 分钟。

| 段落 | 目标时长 | 主要体验 |
|---|---:|---|
| 清晨醒来与山庄初逛 | 8-10 分钟 | 移动、对话、调查 |
| 师姐采药采矿 | 15-18 分钟 | 采集教学、师姐陪伴 |
| 午后山庄跑腿 | 18-25 分钟 | 群像温柔乡、寿宴准备 |
| 傍晚拖延与出发 | 8-10 分钟 | 被催促、贪玩、自责伏笔 |
| 夜入崖洞取酒 | 12-15 分钟 | 回忆互动、洞察 |
| 次日回庄搜证 | 15-20 分钟 | 无力探索、线索确认 |
| 师兄误会与分别 | 15-20 分钟 | 误会、埋葬、战斗教学、书信约定 |

## 4. 主线节点

### P00-01 醒在风止山庄

**场景**：主角卧房、山庄前院  
**玩法**：移动、基础对话、基础调查  
**主要 NPC**：白檀、师弟、厨房弟子  

主角在寿宴前一日清晨醒来。师姐白檀来催他起床，语气亲近，像姐姐也像半个小师父。山庄里已经开始为庄主六十寿辰忙碌。

玩家学习移动、靠近交互点、与 NPC 对话。此处不出现战斗教学，也不出现危机提示。

**关键目的**：
- 让玩家第一次感到山庄是熟悉、安全、有人照看的地方。
- 建立师姐“嘴上催，实际护”的关系基调。
- 引出今天的主目标：寿宴准备。

### P00-02 师姐带你上山

**场景**：山庄外小坡、药草地  
**玩法**：采药教学  
**主要 NPC**：白檀  

师姐带主角去山庄边缘采药。主角抱怨自己都这么大了才第一次正式学，师姐解释：小时候主角太容易逞强，她怕他摔伤、割伤、被蛇虫惊到，所以一直不让他跟着采药；最近主角缠得太厉害，她才松口。

采药教学通过师姐台词和底部文学化提示完成，不使用强制弹窗。

**关键目的**：
- 合理解释此前为何没学过采药。
- 让采集教学成为师姐关系戏，而不是系统说明。
- 突出主角被保护得太好，为灭门后的失护感做铺垫。

### P00-03 第一次采矿

**场景**：浅溪边、小矿脉  
**玩法**：采矿教学、环境观察  
**主要 NPC**：白檀  

师姐教主角识别浅表矿脉，只允许他采安全位置，不让他靠近崖边。过程中两人发现一串动物足迹。师姐判断不是危险猛兽，而是山里常见的通灵野兽经过。

师姐顺势提到：世间有些动物通人性，若驯养得当，能驮人远行。主角半开玩笑说以后也想有一匹坐骑，师姐笑他连山路都走不稳。

**关键目的**：
- 完成采矿教学。
- 埋下未来坐骑系统伏笔。
- 保持日常幸福感，不在此处透露山庄外面的危险与阴谋。

### P00-04 山庄跑腿

**场景**：厨房、药房、练武场、正堂周边  
**玩法**：送物、对话、轻调查  
**主要 NPC**：白檀、师弟、厨娘、若干门人  

玩家回到山庄，为寿宴做一组轻量跑腿：送药草、搬酒盏、找红绳、帮厨房确认食材、替师弟传话。每个小任务都短，重点是让玩家走过山庄各处，认识这个家。

师姐第一次提醒主角：别忘了去崖洞取三年前封下的药酒。主角答应得很快，但没有立刻去。

**关键目的**：
- 建立山庄群像。
- 让玩家对空间产生熟悉感。
- 开始埋“主角拖延取酒”的行为事实。

### P00-05 书房小事

**场景**：庄主书房  
**玩法**：调查书架、送物、短对话  
**主要 NPC**：庄主  

主角被安排给庄主书房送物。玩家可以调查书架、棋盘、旧灯、墙上字画，并短暂看到暗格位置，但主角不理解其意义。

庄主和主角有一段温和谈话，不揭露身世，不解释外部危机，只说类似“人这一生，总要知道什么该争，什么该止”。这句话在灭门后回想会变重。

**关键目的**：
- 让玩家提前见过书房暗格，方便灭门后理解“这里被翻过”。
- 保持庄主的温柔与隐瞒，不让他变成谜语人。
- 为“善意保护也是悲剧种子”做轻触。

### P00-06 拖到天黑

**场景**：山庄各处  
**玩法**：自由互动、温和催促  
**主要 NPC**：白檀、门人群像  

傍晚临近，师姐再次催促主角去崖洞取酒。主角仗着后山路熟，觉得自己闭着眼也能走过去，于是继续被山庄里的小事绊住。

这里不设置硬倒计时，也不惩罚玩家闲逛。NPC 的对话会逐渐转为温和提醒：“快去吧，再晚山路不好走。”玩家仍可继续完成少量日常互动。

**关键目的**：
- 让拖延成为角色行为，而非玩家失败。
- 强化灭门后的自责：“如果我早点去，或者早点回……”
- 在不破坏温柔日常的前提下推进到入夜。

### P00-07 夜入崖洞取酒

**场景**：后山路、后山崖洞夜版  
**玩法**：探索、追查、内心独白、取药酒  
**主要 NPC**：无现场 NPC；师姐以回忆出现  

主角入夜后抵达崖洞。崖洞不是藏宝室、矿洞或阴谋地点，而是主角和师姐共享过的小秘密基地。所有互动点都服务于回忆。

互动点建议：

| 互动点 | 类型 | 回忆功能 |
|---|---|---|
| 墙上招式刻画 | EnvironmentDetail | 师姐小时候用树枝画过简笔招式，哄主角记风止尺法的走势 |
| 三年陈药酒 | Key Item | 主角与师姐三年前一起封坛，为庄主寿辰准备 |
| 草席与小凳 | EnvironmentDetail | 两人曾在这里避雨、躲懒、偷吃点心 |
| 药壶残香 | EnvironmentDetail | 师姐曾给主角煎防寒药，嫌他不肯好好喝 |

取酒后因天黑路险、山雨、崖路湿滑或体力不支，主角决定在崖洞暂歇一夜。

**关键目的**：
- 把现有崖洞洞察内容转向“每处互动都勾起回忆”。
- 让夜宿崖洞合理成立。
- 让崖洞成为幸存原因，同时保持它的情感属性。

### P00-08 异常安静，回庄

**场景**：后山路、山庄大门  
**玩法**：低速探索、气氛演出  
**主要 NPC**：无  

后半夜或次日清晨，主角被异常的静惊醒。虫鸣全消，连风声都像停了。玩家沿后山路回庄，山门敞开，平日晨练和厨房声都消失。

此段不立刻展示惨案全貌，而是通过空场景逐步让玩家意识到不对劲。

**关键目的**：
- 从幸福日常切入失声空白。
- 让玩家主动向前确认，而不是被过场动画直接告知。
- 为“风止”二字的反讽创造静默前奏。

### P00-09 惨案搜证

**场景**：练武场、正堂、庄主书房  
**玩法**：洞察、调查、关键物拾取  
**主要 NPC**：无可对话 NPC  

玩家在山庄中逐步确认灭门事实。此段不是战斗关，不能出现追杀战或可击败敌人。

关键线索：

| 线索 | 场景 | 叙事功能 |
|---|---|---|
| 无人拔剑 | 练武场 / 正堂 | 所有人在毫无戒备下被杀，风止“不争”成为死因 |
| 师父倒在庄训前 | 正堂 | 庄主面朝“风过万里，止于此山”的石壁而死 |
| “风止”二字被血划过 | 正堂 | 凶手对山庄理念的嘲讽 |
| 书房暗格空了 | 书房 | 有人目标明确地取走某样东西 |
| 半封血书 | 书房 / 师父身侧 | “风起渊底，鹤归无枝”，唯一可带走线索 |
| 师姐不在尸体中 | 全庄清点 | 建立长期悬念：被掳、逃脱，还是另有隐情 |

主角此时不应立刻说出成熟复仇宣言。更合适的情绪是混乱、否认、寻找师姐、无法理解。

**关键目的**：
- 让玩家用探索确认失去。
- 给第一章追查提供唯一方向，但不直接指认凶手。
- 确立师姐失踪悬念。

### P00-10 师兄归山，误会与分别

**场景**：山门、正堂、后山墓地或山庄墓地  
**玩法**：误会系统首次体验、对话澄清、共同埋葬、战斗教学、书信约定  
**主要 NPC**：师兄  

师兄因外出采买寿宴物资，晚于主角回山。他看见满门皆灭、主角独活，且主角手中有血书或遗物，产生误会。

误会来源不是主角身世。师兄不知道主角与澜国的联系，只能从“为什么只有你活着”这一点怀疑。此处触发误会系统首次体验，但必须通过对话解除，不进入真正生死战。

误会解除后，两人共同埋葬门人。共同埋葬是序章情感收束点，优先级高于信息揭露。

埋葬后，师兄教授主角剩余未习得的风止尺法基础。战斗教学在此发生，作为临别传承与生存保障。最后两人约定分头追查，并保留书信联系，师兄成为主角第一位远方联系人。

**关键目的**：
- 首次引入误会系统，但保持师兄可信、痛苦、并非不可理喻。
- 把战斗教学从“游戏教程”改成“家破之后必须学会自保”。
- 用共同埋葬把“家已不在”落到具体行动。
- 自然引入书信系统。

## 5. 系统引入顺序

| 系统 | 引入节点 | 教授者 / 触发者 | 说明 |
|---|---|---|---|
| 移动与交互 | P00-01 | 自然 | 在山庄日常中完成 |
| 对话 | P00-01 / P00-04 | 师姐、师弟、群像 NPC | 不做弹窗式教学 |
| 采药 | P00-02 | 师姐 | 师姐保护欲解释为何此前没学 |
| 采矿 | P00-03 | 师姐 | 安全边界和采集节奏 |
| 坐骑伏笔 | P00-03 | 师姐 | 通过动物足迹自然提及 |
| 洞察 / 追查 | P00-07 / P00-09 | 场景自然触发 | 崖洞回忆与灭门搜证各承担一次 |
| 误会系统 | P00-10 | 师兄 | 由“独活”造成的信息差触发 |
| 战斗教学 | P00-10 | 师兄 | 误会解除、共同埋葬后进行 |
| 书信 | P00-10 | 师兄 | 分头追查时自然约定 |

## 6. 情绪曲线

```mermaid
flowchart LR
    A["清晨：被照顾"] --> B["上午：师姐教采集"]
    B --> C["午后：山庄群像温柔乡"]
    C --> D["傍晚：拖延取酒"]
    D --> E["夜晚：崖洞回忆"]
    E --> F["清晨：异常安静"]
    F --> G["回庄：无法理解"]
    G --> H["师兄：误会与质问"]
    H --> I["共同埋葬：承认失去"]
    I --> J["临别传承：被迫长大"]
```

灭门前的全部节点都服务于“这是家”。灭门后不急着给答案，而是让玩家经历“不理解”。序章末尾才从“不理解”过渡到“我必须活下去查明白”。

## 7. 关键叙事约束

1. 师姐不在尸体中。
   - 序章不解释她的去向。
   - 不给玩家直接证据证明她被掳或主动离开。

2. 废墟中不出现可直接指认凶手的信物。
   - 没有暗令、令牌、门派徽记。
   - 半封血书是唯一明确线索。

3. 主角旧玉不是废墟线索。
   - 旧玉自幼佩戴。
   - 后期澜国段才被他人认出其身世意义。

4. 师兄不知道主角身世。
   - 师兄误会只来自“唯主角独活”。
   - 不能让师兄围绕澜国身份质问。

5. 误会不进入生死战。
   - 师兄可以拔高语气、逼问、短暂失控。
   - 但必须通过对话和事实澄清解除。

6. 战斗教学发生在误会解除后。
   - 教学的叙事理由是临别传承。
   - 不提前在灭门前日常中教学战斗。

## 9. 与现有文档的对齐和需要修订处

本设计与主线文档中的序章尾段一致：

- 师兄采买回山后触发误会。
- 误会通过对话解除，不进入生死战。
- 共同埋葬是情感高潮。
- 师兄临别传承承担战斗教学。
- 分别追查时自然引入书信系统。

需要后续修订的旧口径：

1. `design/gdd/main-narrative.md` 中“陪师弟练功”容易被误读为灭门前战斗教学，应改为“陪师弟日常互动”或“与师弟跑腿玩闹”。
2. `design/gdd/main-narrative.md` 中“和师姐去后山（师姐欲言又止）”若用于序章日常，容易提前污染幸福感；建议改为“和师姐上山采集，发现动物足迹并埋坐骑伏笔”。
3. 已实现的崖洞洞察内容中，`cave_loose_brick` 建议在后续内容生产中改为墙上招式刻画，统一为回忆触发点。

## 10. 首版实现建议

首版不要一次性追求 90 分钟完整版。推荐先实现可玩骨架：

1. P00-01 到 P00-03：师姐采集线完整可玩。
2. P00-04 到 P00-06：山庄跑腿保留 3-4 个代表性 NPC。
3. P00-07：复用现有后山崖洞场景，将互动文本调整为回忆向。
4. P00-08 到 P00-09：制作灭门后山庄最小可搜证路径。
5. P00-10：先完成师兄误会对话、共同埋葬、临别传承的剧情骨架；战斗教学可作为独立 story 接入。

验收标准：

- 玩家能在灭门前明确记住师姐、庄主、至少 2 名门人。
- 玩家能理解主角为何去崖洞、为何夜宿、为何独活。
- 玩家能在灭门后主动发现至少 5 个关键线索。
- 师兄误会成立但不显得不可理喻。
- 战斗教学发生在误会解除与共同埋葬之后。
- 序章结束时，玩家目标从“参加寿宴”转变为“带着血书下山查明真相，并寻找师姐”。
