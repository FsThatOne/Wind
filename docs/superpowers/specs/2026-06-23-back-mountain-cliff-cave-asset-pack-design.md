# 后山崖洞资产包设计

> **项目**：风止 (FengZhi)
> **场景**：后山崖洞
> **状态**：设计已在对话中确认，等待实现计划
> **日期**：2026-06-23
> **美术方向**：16-bit 像素武侠，纯 2D，等距菱形
> **Tile 规格**：PNG32 / RGBA，64x32，2:1 无缝等距菱形 tile

## 1. 目标

为序章场景“后山崖洞”制作一套小而完整、可测试、可扩展的资产与 Tiled 地图包。

这个崖洞不是野外副本、矿洞、遗迹、怪物巢穴或藏宝室。它是风止山庄后山一处有人使用过的储物洞：

- 用来藏酒和存放杂物。
- 是主角和师姐共享的小秘密基地。
- 序章中，主角来这里取三年陈药酒，因此避过山庄灭门。
- 同一个空间需要同时承载“灭门前温暖日常”和“灭门夜静得不对劲”的情绪反差。

首版使用 `16x16` Tiled 地图，先验证布局、资产比例、碰撞和剧情标记；如果不够大，后续再扩成 `24x24` 或 `32x32`。

## 2. 交付物

### 2.1 地面 Tile 图集

- 一张 PNG32 / RGBA tile atlas。
- 单块 tile 尺寸：`64x32`。
- 投影：2:1 等距菱形。
- 风格：16-bit 像素武侠。
- 用途：洞内石地、低矮边界、储物区地面细节、潮湿石面变化、路径可读性提示。

### 2.2 独立物件 Sprite

- 独立透明 PNG32 / RGBA。
- 每个物件底部 anchor 对齐 tile 基准线。
- 物件通过 Tiled Object Layer 放置，不烘焙进地面 tile。
- 宽物件可以横跨 1-2 个 tile，但仍作为独立运行时对象处理。

### 2.3 主角行走图集

- 角色：复用现有 16-bit 主角资产，不重新设计新角色。
- 方向：`NE`、`SE`、`SW`、`NW`。
- 动画名：`walk_ne`、`walk_se`、`walk_sw`、`walk_nw`。
- 帧数：每方向 4 帧，总计 16 帧。
- 单帧画布：沿用现有 `128x128`。
- 脚底对齐每帧画布底部。

### 2.4 Tiled 地图

输出两份独立 `.tmx`，共享同一套 tileset 和物件 PNG：

- `back_mountain_cliff_cave_day.tmx`
- `back_mountain_cliff_cave_night.tmx`

两份地图保持大体一致的布局，让玩家感到“同一个熟悉的地方变了”。

## 3. 空间布局

采用已确认的 **“储物区 + 小窝”** 布局。

在 `16x16` tile 范围内：

- 左侧：通向后山路径的出入口。
- 左 / 中主洞室：实用储物区，摆放药酒、木架、竹筐、低木箱。
- 中间连接段：储物区通往秘密基地小窝的短通道。
- 右侧：主角和师姐的小秘密基地，包含草席 / 蒲团、小木凳、微弱油灯、师姐记号。
- 下侧 / 右下：潮湿石面与浅水洼，增加洞内氛围，但不做主要通路阻挡。

布局优先保证可读性，不追求迷宫感。它应该像一个安全、熟悉、被认真使用过的藏身处，而不是战斗副本。

## 4. Tileset 范围

首版 tileset 共 24 个 tile，建议按 6 列 x 4 行排列。

### 4.1 基础地面

- 干石地。
- 湿石地。
- 较平整的储物区石地。
- 带苔痕的石地。

### 4.2 地面变化

- 碎石点缀。
- 浅水洼。
- 泥水边缘。
- 阴影角落。

### 4.3 边界与低矮结构

- 洞壁脚线。
- 低矮石台边。
- 储物区木板垫底。
- 洞壁阴影过渡。

### 4.4 可读性提示

- 经常行走而磨亮的石面。
- 右侧小窝较干净的石面。
- 酒坛放置压痕。
- 蒲团 / 草席下的地面压痕。

日常版与夜版复用同一套 tile。情绪差异通过地图对象状态、色调元数据和场景光照来表达，不制作双倍 tile。

## 5. 物件 Sprite 范围

制作 10 个独立透明物件：

| 资源 | 用途 | 碰撞 |
|---|---|---|
| `wine_jar_single.png` | 单个封泥药酒坛 | 可选小阻挡 |
| `wine_jars_group.png` | 主取酒点，2-3 个酒坛组合 | 阻挡 |
| `storage_shelf.png` | 靠墙储物木架，摆小物和杂物 | 阻挡 |
| `bamboo_basket_herbs.png` | 竹筐与晒干药草 | 可选小阻挡 |
| `cloth_bundle.png` | 储物布包 | 可选小阻挡 |
| `wooden_crate_low.png` | 低木箱，储物杂物 | 阻挡 |
| `rest_mat.png` | 旧蒲团或草席，夜版暂歇触发点 | 非阻挡 marker |
| `small_stool.png` | 小木凳，体现秘密基地生活感 | 可选小阻挡 |
| `sister_mark.png` | 师姐留下的小布条 / 刻痕 / 纸签记号 | 非阻挡 marker |
| `oil_lamp_dim.png` | 小油灯，日常版温暖，夜版微弱或将熄 | 非阻挡 |

物件必须朴素、生活化。避免剑、墓葬物、宝箱、怪物残骸、矿车、古遗迹等会把场景带偏的元素。

## 6. Tiled 地图契约

### 6.1 地图设置

- 地图尺寸：`16x16`。
- Orientation：isometric。
- Tile size：`64x32`。
- 可以使用外部 tileset 引用。
- 物件使用 Tiled 等距地图对象坐标放置，视觉底部对齐目标 tile 基准线。

### 6.2 图层

使用这些稳定图层名：

- `Ground`：基础石地、湿地、浅水洼。
- `Terrain`：苔痕、碎石、酒坛压痕、草席压痕、低矮地面细节。
- `Structures`：酒坛、木架、木箱、竹筐、油灯、小凳、草席、师姐记号。
- `Overlay`：前景洞壁阴影或较高岩边，必要时遮挡角色上半身。
- `Collision`：不可见碰撞数据，覆盖岩壁、酒坛组、木架、木箱、深水洼或阻挡物。
- `LogicMarkers`：剧情与交互 marker 对象层。

### 6.3 逻辑标记对象

必需 marker 名称与作用：

| Marker | 类型 | 日常版行为 | 夜版行为 |
|---|---|---|---|
| `exit_to_back_mountain` | exit | 返回后山 | 返回后山，或在剧情触发后临时阻断 |
| `wine_pickup` | interactable | 查看药酒 | 触发取药酒目标 |
| `storage_shelf` | inspect | 储物与生活气息说明 | 安静、异样的储物说明 |
| `memory_marker` | inspect | 师姐记忆，温暖 | 师姐缺席感，压低情绪 |
| `rest_spot` | trigger | 仅查看 | 触发暂歇一夜 |
| `blocked_rock` | blocker | 环境阻挡 | 环境阻挡 |
| `blocked_storage` | blocker | 储物阻挡 | 储物阻挡 |

每个逻辑对象都应包含：

- `id`
- `type`
- `name`
- `enabled`
- `interaction_id`
- `chapter_state`
- `mood`

### 6.4 日常版与夜版差异

日常版：

- 强调熟悉、安全、有人生活过，以及师姐记忆。
- `wine_pickup` 可以查看，但不推进灭门夜触发。
- `rest_spot` 仅可查看，不触发过夜。
- `mood = warm_daily`。

夜版：

- 强调安静、异样、灭门事件前的不祥。
- `wine_pickup` 是当前主动目标。
- `rest_spot` 在取酒后触发暂歇一夜。
- `memory_marker` 仍存在，但视觉和文本都更克制。
- `mood = silent_night`。
- `chapter_state = prologue_massacre_trigger`。

## 7. 主角图集契约

主角图集先从现有 16-bit 主角资源改制，不直接重新生成。

### 7.1 帧布局

- 4 个方向。
- 每方向 4 帧。
- 推荐最终图集形状：4 行 x 4 列。
- 行顺序：`walk_ne`、`walk_se`、`walk_sw`、`walk_nw`。
- 单帧尺寸：`128x128`。
- 全部帧为透明 RGBA。

### 7.2 对齐

- 脚底 / bottom anchor 对齐画布底边。
- 脚底中心在每帧中保持稳定。
- 角色身体可以明显高于 `64x32` tile footprint；只要求脚底对齐 tile 基准线。
- 帧间不能出现明显缩放漂移或跳脚。

### 7.3 来源策略

首版：

- 从 `assets/generated/sprites/main-character-16bit-8dir/` 中抽取或复用当前 `NE`、`SE`、`SW`、`NW` 行走帧。
- 重命名并组装成 iso4 图集。
- 统一透明边距和脚底 baseline。

只有在现有斜向帧放进 64x32 等距地图后观感明显不对时，才进入重新生成版本。

## 8. 验收标准

资产包完成时必须满足：

- 所有可见 PNG 都是 PNG32 / RGBA。
- 核心地面 tile 在拼接预览中没有明显接缝。
- 物件背景透明，底部 anchor 稳定。
- 两份 `.tmx` 都能在 Tiled 中打开。
- 图层名与本契约完全一致。
- `Collision` 存在，并阻挡岩壁、储物杂物、木架、酒坛组等不可通行区域。
- 从左侧出口到取酒点和右侧小窝都有可行走路径。
- `LogicMarkers` 包含全部必需对象，名称和属性稳定。
- 日常版与夜版能明显看出是同一个空间，但交互状态和情绪不同。
- 主角 4 向图集 baseline 一致，无边缘裁切。

---

## 9. 不在本次范围内

- 扩展为完整 `24x24` 或 `32x32` 洞穴。
- 后山外部入口场景。
- 古遗迹、矿洞、战斗竞技场、怪物巢穴、藏宝室变体。
- 师姐专用角色 sprite。
- 为每个 marker 写完整对话文本。
- Godot 场景集成与 TileMapLayer `.tscn` 接入。
- 除元数据 / tint 备注之外的运行时光照实现。

---

## 10. 后续扩展

如果 `16x16` 版本实际游玩后显得太小：

- 扩展到 `24x24`，保留左侧储物区和右侧秘密基地小窝。
- 增加一个上方小储物壁龛和一个下方潮湿支洞。
- 继续保持 day/night 两份 `.tmx` 结构。
- 优先复用现有 tileset 和物件，再考虑追加新美术。
