# 第一个山洞可玩场景设计

> 日期：2026-06-20  
> 状态：已获用户批准，待实现计划  
> 目标项目：`feng-zhi` Godot 原型项目  
> 现有场景：`feng-zhi/StartCave.tscn`

## 目标

这个山洞是《风止》前期中段的一个小型探索验证场景，不是开场醒来场景，也不承载灭门剧情。玩家进入山洞是为了取得任务物品“寿酒”，并在探索过程中体验移动、调查、内心独白、洞察提示和简单拾取。

目标体验时长为 3-5 分钟。场景语气应保持温暖、熟悉、轻松，重点表现主角与师姐的日常亲近感，以及师姐曾陪主角练功的记忆。

## 范围

本次实现验证以下内容：

1. 玩家能在山洞内顺畅移动。
2. 玩家靠近物件能看到调查提示并交互。
3. 调查能触发主角内心独白。
4. 洞察达标时能出现额外提示或追查入口。
5. 玩家能获得任务物品“寿酒”和一个普通可拾取奖励。

本次不实现以下内容：

- 战斗。
- 正式存档。
- 场景切换。
- 复杂 UI 美术。
- 任务日志。
- 灭门或主线真相揭示。
- 正式背包系统接入。

## 动线

场景采用“中央枢纽”动线。

玩家从左侧入口进入，先自然走向中央桌和床附近，再自由查看周围物件。右侧酒坛或货架承载主目标“寿酒”；前景木箱承载可选拾取；墙面练功痕迹和中央桌承载师姐相关文本；左侧杂物或药篓承载生活化调查。

推荐自然路径：

入口 → 中央桌 → 墙面练功痕迹 → 右侧寿酒 → 可选宝箱 / 药篓 → 离开

玩家不需要按固定顺序调查。只有“寿酒”是主目标，其他交互点是可选探索内容。

## 交互点

### 1. 中央桌：师姐纸条

类型：调查 + 内心独白  
作用：建立师姐调皮、熟悉、亲近的日常感。

交互内容：

- 玩家靠近中央桌时显示调查提示。
- 调查后显示师姐留下的小纸条。
- 纸条语气轻松，像是在逗主角。

示例文本：

> 小师弟，若你又把酒坛认成药坛，回来罚你抄剑谱。

主角独白方向：

> 她明知道我早分得清了，还是每回都要这样写。

### 2. 墙面练功痕迹：洞察点

类型：普通调查 + 洞察追查 + 内心独白  
作用：验证洞察提示，同时表现师姐曾陪主角练功。

普通调查：

- 玩家看到墙上的旧招式图、划痕或批注。
- 普通文本只说明这是练功留下的痕迹。

洞察达标后：

- 若测试属性 `insight >= threshold`，显示额外洞察提示。
- 玩家选择追查后，发现师姐曾在旁边补了几笔，帮主角纠正起手式。

独白方向：

> 那一笔是她补的。她总说我腕太硬，剑未出，意先绷住了。

### 3. 右侧酒坛 / 货架：寿酒

类型：任务物品拾取  
作用：完成场景主目标。

交互内容：

- 玩家靠近右侧酒坛或货架时显示调查提示。
- 调查后获得任务物品“寿酒”。
- 寿酒只能拾取一次。
- 拾取后提供明确反馈。

反馈文本：

> 取得：寿酒

重复调查文本方向：

> 寿酒已经取好了，回去莫要耽搁。

### 4. 前景木箱：普通宝箱

类型：可选拾取  
作用：验证宝箱 / 一次性拾取反馈。

交互内容：

- 玩家靠近前景木箱时显示调查提示。
- 第一次调查获得少量实用物品。
- 宝箱只能拾取一次。

奖励：

- `止血散 x1`

重复调查文本方向：

> 已经翻过了，里头只剩些干草和旧绳。

### 5. 左侧杂物 / 药篓：生活化调查

类型：调查 + 内心独白  
作用：建立山庄日常储物洞的生活气。

交互内容：

- 玩家调查药材、杂物或药篓。
- 不给物品，只触发轻量独白。

示例文本：

> 这些药材多半是师姐晒的。她总说我分不清辛温寒凉。

## 技术边界

先在 `feng-zhi` Godot 原型项目中实现轻量本地逻辑，不接正式 Foundation / Feature 层服务。

建议结构：

- 玩家移动：一个 `CharacterBody2D` 主角，支持方向键和 WASD。
- 交互检测：每个调查点使用 `Area2D` 或距离检测。
- 提示显示：靠近可交互物件时显示“调查”提示。
- 交互状态：场景本地状态记录已调查、已拾取、寿酒是否获得。
- 内心独白：底部简洁文字框，显示 1-2 句，确认键关闭。
- 洞察提示：测试属性满足门槛时，在练功痕迹处显示额外追查入口。
- 物品反馈：底部或右上显示“取得：寿酒 / 止血散 x1”。

实现优先级应以可玩性为先。交互文本、提示 UI 和角色移动可以使用朴素样式，只要信息清楚、运行稳定。

## 验收标准

1. 玩家能从左侧入口移动到中央、右侧和前景区域。
2. 5 个交互点都能靠近并触发提示。
3. 中央桌和药篓能触发内心独白。
4. 墙面练功痕迹能触发普通调查。
5. 洞察达标时，墙面练功痕迹能触发额外追查文本。
6. 寿酒只能拾取一次，拾取后有明确反馈。
7. 宝箱只能拾取一次，重复调查显示已翻过的反馈。
8. 场景在 Godot 4.7-stable 中运行无报错。
