## 二、G-1 进度循环优先级信号（设计决策）

### 决策：叙事引导式提示

- **触发时机**：跨日后首次跨场景 / 旅店休息之后
- **形式**：主角自言自语（内心独白），提示当前优先事项或让玩家做选择
- **原则**：
  - 不在每日开始时弹出（避免"每日任务"的游戏感）
  - 引导而非强制，玩家可忽略提示
  - 独白内容关联当前叙事进度（如"师父的血书上有个暗号……我该去查查"）

## 三、G-2 认知负荷：系统解锁时间线（设计决策）

### 核心原则：不超过第二章全部解锁

| 阶段 | 叙事场景 | 新增系统 | 累计追踪维度 |
|------|---------|---------|------------|
| **序章前半** | 师门生活→灭门事件 | 移动/场景、对话、战斗（基础）、感情系统（师兄弟/师傅/师姐）、NPC 态度（将死之人态度死后固定） | 5 |
| **序章尾段** | 师兄归来→误会→分别 | +误会系统（师兄误会主角）、活江湖层·书信（分别时约定通信） | 7 |
| **第一章** | 镖局岁月 | +心境双轴、自然日/体力、物品/装备、锻造/炼丹（镖局采药采矿）、活江湖层·传闻/暗号（老镖师教授） | 12 |
| **第二章** | 独行江湖 | +顿悟突破（生死危局触发）、探索/洞察 | **13（全解锁）** |

### 各系统解锁的叙事锚点

- **感情+NPC 态度**：序章师门生活中与师兄弟/师傅/师姐自然互动
- **将死之人态度**：师门灭亡后态度值固定不再变化（叙事时刻）
- **误会系统**：师兄归山误会主角独活=内奸（详见下方场景设计）
- **书信系统**：分别时约定追查方向→植入书信通信
- **活江湖层·传闻/暗号**：老镖师作为江湖引路人教授
- **锻造/炼丹**：镖师走镖必备技能（采药采矿→锻造兵器/炼药），填充主角镖局成长时光
- **顿悟突破**：第二章生死危局中自然触发→顺势教学

## 四、序章尾段：师兄误会场景设计

### 场景流程

```
灭门惨案 → 主角幸存（序章主体）
→ 师兄晚于主角归山
→ 师兄进入师傅房间，主角已收拾好心情和遗物
→ 师兄质疑：满门皆灭，唯你独活
→ 误会形成：师兄准备厮杀
→ 对话系统：主角解释生还原因 → 误会解除
→ 共同埋葬门人
→ 分别下山，各自追查
→ 分开时约定追查方向 + 通信方式 → 书信系统教学
```

### 叙事功能

1. **误会系统教学**：玩家第一次体验误会的形成→对话解除流程
2. **书信系统教学**：分别后建立通信渠道
3. **情感深度**：共同埋葬门人是序章的情感高潮
4. **后续铺垫**：师兄成为第一个远方联系人，后续书信推动剧情

## 五、设定变更

### 变更 1：师门武器改为尺

- **原设定**：未明确（暗示刀剑）
- **新设定**：师门善用**尺**（铁尺/玉尺）
- **理由**：尺杀气不重，符合师门出世定位。刀剑过于凌厉，与师门哲学矛盾
- **主角武器**：**玉尺**（比铁尺更不能伤人，体现师傅对主角的保护/期许）
- **影响 GDD**：character-attributes（武器类型）、martial-arts（招式体系）、combat-system（武器相关平衡）、game-concept（若有武器描述）
- **已同步**（2026-06-07）：
  - `martial-arts-system.md`：风止剑法 → **风止尺法**，剑道 → 武道
  - `game-concept.md`：风止剑法 → 风止尺法

### 变更 1b：师门武学定义

- **门派重心法、轻招式，重出世无为，唯养心性**
- **内功心法**：**风止心经**
- **武学（尺法）**：**风止尺法** — 围绕尺和「风止」哲学展开，只包含**柔**和**巧**两种招式（无刚），强支撑出世不攻的门派侧写
- **武学重意不重力**：为避免普通弟子贪多嚼不烂，阶段性传授。只有高天赋的/负责下山采购物资的弟子（如大师兄）才传授全套
- **主角状态**：贪玩，未专心练习，因此未能完全习得所有招式
- **门人武器**：从小入门的门人大多用**玉尺**
- **外来者**：少数后入门的外来者可保留原有武功（仅做描述，不展开设计）
- **主角后续**：主角后续可以学习/使用剑等其他武器
- **结局名保留「剑」字**：孤剑斩世/风止剑鸣/剑覆苍生 — 剑作为江湖意象保留

#### 招式命名（效果后续再议）

| 招式名 | 类型 | 描述 |
|--------|------|------|
| 敛虚息 | 柔 | 收敛内气，周身风意不外泄，筑牢内防根基 |
| 泯尘念 | 柔 | 抛却胜负心，契合出世无为之道 |
| 环风抱元 | 柔 | 尺身旋划圆弧，如风环周身，全方位护住头、胸、腰三路，密不透风 |
| 疏风隔尘 | 柔 | 尺身横隔二人之间，拉开距离，如风隔尘埃，主动终止缠斗 |
| 长风不语 | 柔 | 身形缓步游走，尺隐于周身风势之中，看似无招实则处处皆防，对手难寻破绽 |
| 顺天游 | 巧 | 心神融于长风，不执攻守，随性而为 |
| 轻点封 | 巧 | 尺梢轻点经脉关节，封其运力，点到即止 |
| 逐风引浪 | 巧 | 尺梢轻搭对方兵器，顺着力道引偏攻势，如逐风而行，不硬碰、不硬挡 |
| 回风绕袖 | 巧 | 尺身回旋缠绕，借力打力，将对手劲力折返消解，自身不发半分攻击 |

#### 战斗教学时机变更

- **原设定**：序章前段教学
- **新设定**：移至大师兄回山后、主角与师兄下山分别追凶之前
- **教学内容**：大师兄教授主角剩余未习得的风止尺法招式，顺势讲解战斗方式、基础克制关系（刚/柔/巧三角）和武学分类
- **叙事功能**：师兄弟共同面对灭门之痛后的实用传承，既是临别赠礼也是生存保障

- **待设计**：需在 martial-arts-system GDD 中补充风止尺法的具体招式体系和效果

### 变更 2：主角身世保密

- **设定**：师傅对外宣称主角是"下山采药时意外捡到的可怜孩子"
- **知情人**：仅师傅和师姐知道主角真实身世（澜国出生，三岁被托付）
- **叙事意义**：师兄不知道主角身世 → 不会从身世角度怀疑，只从"独活"角度怀疑
- **影响 GDD**：main-narrative（身世揭露节点）、npc-state（NPC 知情状态）
