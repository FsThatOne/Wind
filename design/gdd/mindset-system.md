# 心境双轴 (Mindset Dual-Axis System)

> **Status**: In Design
> **Author**: user + agents
> **Last Updated**: 2026-06-03
> **Implements Pillar**: Pillar 2 (每个选择必须有重量), Pillar 3 (武侠味先于游戏味)

## Summary

心境双轴是《孤山遗剑》的道德/心理状态系统，用一张隐式 2D 图（执念↔释怀 × 入世↔出世）追踪玩家通过对话选择、关键行为和剧情抉择积累的心理倾向。它决定 5 种结局走向、NPC 对玩家的态度变化、武学获取倾向，以及视觉风格的渐变。系统对玩家完全隐式 — 不显示数值，仅通过文学语言和视觉反馈传递心境状态。

> **Quick reference** — Layer: `Core` · Priority: `MVP` · Key deps: `对话系统, NPC 状态管理(soft)`

## Overview

心境双轴是《孤山遗剑》的核心心理状态系统，通过一张隐式的 2D 坐标图追踪主角的内心演变。横轴为**执念↔释怀**（对师门血仇的态度），纵轴为**入世↔出世**（对江湖命运的参与度）。玩家在对话选择、关键剧情抉择和行为中无意识地推动坐标移动，最终落入 5 个心境区域之一，决定游戏的结局走向。

作为 Core 层系统，心境双轴从对话系统接收 `mindset_shift` 事件作为输入，向感情系统、NPC 状态管理和朦胧化 UI 输出当前心境状态。它的设计核心是**隐式性** — 玩家永远不会看到"你的执念值为 73"，取而代之的是：对话中的文学暗示（"此言带几分执念"）、视觉色调的渐变、NPC 对你态度的微妙变化、以及终幕时"你突然理解了自己一路走来成为了怎样的人"的顿悟时刻。

系统还管理一个隐藏的第三维度 — **魔道深渊**：当执念值极端化且特定条件满足时，触发第 5 个隐藏结局（剑覆苍生），这是对"如果复仇之路走到尽头，连侠义本身也被抛弃"的回答。

## Player Fantasy

**"我走到终幕才发现，这一路的每个选择都在悄悄塑造我 — 我成为了一个我自己选择成为的人，而不是被命运推着走的棋子。"**

心境双轴服务两层玩家幻想：

**选择时的直觉重量** — 当玩家在仇人面前选择"留你一命"时，对话中的文学暗示（"话中有释怀之意"）让玩家隐约感到"我正在成为某种人"。这不是一个道德滑杆的计算题，而是武侠小说里"一念之间"的心理博弈。玩家不知道精确后果，但**直觉告诉他这个选择有分量**。

**结局时的命运回响** — 当终幕色调变化、NPC 以不同态度面对你、你获得的结局标题揭示了"你是谁"时，玩家回顾全程，发现每一个曾经"随手一选"的对话都在推动命运。仙剑式的宿命感不是被动接受剧情，而是"我的选择编织了这个命运"的主动感。

**支柱对齐**：
- **Pillar 2**（选择有重量）— 心境是选择后果的累积，让每个选择"被记住"
- **Pillar 3**（武侠味先于游戏味）— 不显示数值，用文学语言和视觉变化传达心境

## Detailed Design

### Core Rules

**1. 双轴坐标模型**

心境状态用一个 2D 坐标 `(obsession, worldly)` 表示：

- **横轴 obsession（执念↔释怀）**：值域 0–100。0 = 完全释怀，100 = 极端执念。初始值 = 50（中立）。
- **纵轴 worldly（入世↔出世）**：值域 0–100。0 = 完全出世，100 = 极度入世。初始值 = 50（中立）。

坐标原点 (50, 50) 代表"尚未做出足够选择来定义自己"的初始状态。

**2. 心境位移规则**

心境位移由对话系统的 `mindset_shift(axis, delta)` 事件触发。规则：

- 每次位移量 `delta` 由对话节点上配置，典型值为 ±3 到 ±8
- **关键剧情抉择**（如杀/留仇人、承诺/拒绝感情）产生 **±10 到 ±15** 的大位移
- 位移被 clamp 到 [0, 100] 范围
- **衰减机制**：无。已做出的选择永远不会被时间消磨 — 你的过去定义你

**3. 五区域结局映射**

2D 坐标空间被划分为 5 个结局区域：

| 结局 | 区域条件 | 终幕色调 | 核心叙事 |
|------|---------|---------|---------|
| **白衣行天下** | obsession < 40 AND worldly ≥ 60 | 江南细腻回暖 | 释怀仇恨，入世济天下，成为被江湖敬仰的侠者 |
| **孤剑斩世** | obsession ≥ 60 AND worldly ≥ 60 | 朱红压顶 | 执念不灭，入世以剑平不平事，成为被惧怕的复仇者 |
| **大隐于市** | obsession < 40 AND worldly < 40 | 烟雨灰蓝 | 释怀仇恨，远离江湖，隐于市井之中 |
| **孤山留剑** | obsession ≥ 40 AND obsession < 60 AND worldly < 40 | 雪白墨黑 | 执念未消但选择退隐，将剑留在孤山，独守师门 |
| **剑覆苍生** (隐藏) | obsession ≥ 85 AND abyss_triggered = true | 全黑 + 一点孤血 | 执念吞噬一切，魔道觉醒，以剑覆天下 |

中间区域（40–60 之间的"模糊地带"）：游戏在终章通过 1-2 个"定局选择"让玩家最终确定结局方向。这些定局选择的选项权重受当前心境坐标影响（更接近某个区域的玩家会看到更贴合那个方向的选项描述）。

**4. 魔道深渊机制**

隐藏的第三维度 `abyss_counter`：

- 初始值 = 0，上限 = 3
- 当满足以下**全部条件**时 +1：(a) obsession ≥ 80 且 (b) 玩家做出了特定标记为"残忍/极端"的选择
- 当 `abyss_counter` ≥ 3 时，`abyss_triggered = true`，解锁魔道结局路径
- abyss_counter **不可逆** — 一旦触发条件累积，无法减少
- 全游戏仅有 4-5 个节点可以触发 abyss_counter，且每个只能触发一次

**5. NPC 反应层**

心境状态通过**区间**（而非精确值）影响 NPC 行为：

| 心境区间 | 区间定义 | NPC 反应类型 |
|---------|---------|------------|
| 低执念 | obsession < 30 | NPC 视你为温和之人，更愿意吐露心声 |
| 中等 | 30 ≤ obsession ≤ 70 | NPC 态度中立 |
| 高执念 | obsession > 70 | NPC 对你心生警惕或畏惧 |
| 低入世 | worldly < 30 | NPC 认为你已心灰意冷，试图劝你回来 |
| 高入世 | worldly > 70 | NPC 视你为江湖中人，更愿意托付任务 |

NPC 反应通过对话系统的 `mindset_check` 条件实现：不同心境区间解锁不同的对话分支。

**6. 武学获取倾向**

心境坐标影响部分武学的获取条件：

- 高执念（≥ 70）可学到攻击性极强的"杀招"类武学
- 高释怀（obsession < 30）可学到内功修炼型武学
- 魔道路线（abyss_triggered）解锁独特的魔道武学
- 具体武学清单由武学组合 GDD 定义，心境系统只提供条件查询接口

**7. 隐式表达原则**

心境系统**永远不向玩家显示任何数值**。反馈方式：

- **对话中的文学暗示**：对话系统在心境选择旁显示暗示（由对话系统 GDD 定义）
- **视觉色调渐变**：场景色调随心境坐标缓慢变化（由朦胧化 UI 系统消费 mindset 数据）
- **NPC 反应变化**：NPC 对玩家态度的微妙改变
- **内心独白变化**：主角的内心独白随心境区间而不同
- **终幕揭示**：5 种结局标题 + 色调 + NPC 最终态度 = 玩家唯一一次"看清"自己心境的完整画面

### States and Transitions

心境系统本身没有复杂的状态机 — 它是一个持续追踪的数据模型。但心境坐标所处的**区间**可视为状态：

| 区间状态 | 进入条件 | 退出条件 | 对外影响 |
|---------|---------|---------|---------|
| **中立 (50,50 附近)** | 游戏开始 | 任意轴偏离 ≥15 | NPC 反应中立，无特殊武学解锁 |
| **执念倾向** | obsession ≥ 65 | obsession 降回 < 65 | NPC 警惕，攻击型武学可用 |
| **释怀倾向** | obsession ≤ 35 | obsession 升回 > 35 | NPC 信任，内修型武学可用 |
| **入世倾向** | worldly ≥ 65 | worldly 降回 < 65 | NPC 委托任务，江湖消息更多 |
| **出世倾向** | worldly ≤ 35 | worldly 升回 > 35 | NPC 劝说回归，隐世线索增多 |
| **魔道边缘** | obsession ≥ 80 AND abyss_counter ≥ 1 | obsession 降回 < 80 | 暗色视觉滤镜，NPC 恐惧 |
| **魔道觉醒** | abyss_triggered = true | 不可逆 | 魔道结局路径解锁 |

区间之间可自由转换（除魔道觉醒外），玩家的选择可以让心境在区间间来回移动。

### Interactions with Other Systems

| 系统 | 方向 | 接口 |
|------|------|------|
| **对话系统** | 对话 → 心境 | `mindset_shift(axis, delta)` 接收心境位移事件 |
| **对话系统** | 心境 → 对话 | `mindset_check(axis, op, threshold)` 提供当前值查询 |
| **感情系统** | 心境 → 感情 | 心境区间影响关系互动的可选项和反应 |
| **NPC 状态管理** | 心境 → NPC | NPC 通过 `mindset_check` 查询玩家心境区间，调整态度 |
| **武学组合** | 心境 → 武学 | 部分武学获取条件依赖 `mindset_check` |
| **朦胧化 UI** | 心境 → UI | 输出当前坐标供视觉系统驱动色调渐变 |
| **主线叙事** | 心境 → 叙事 | 终章结局判定读取心境坐标 + abyss_triggered |
| **存档系统** | 双向 | `(obsession, worldly, abyss_counter, abyss_triggered)` 全量持久化 |

**接口所有权原则**：心境系统**拥有**坐标数据，其他系统只能查询（read-only），不能直接修改。唯一的写入路径是通过 `mindset_shift` 事件。

## Formulas

### 心境位移公式 (Mindset Shift)

`new_value = clamp(current_value + delta, 0, 100)`

| 变量 | 符号 | 类型 | 范围 | 描述 |
|------|------|------|------|------|
| 当前心境值 | `current_value` | int | 0–100 | 指定轴上的当前值 |
| 位移量 | `delta` | int | -15 to +15 | 由对话节点配置。正值 = 向执念/入世方向；负值 = 向释怀/出世方向 |

**输出范围**：0–100（clamp 后）
**示例**：obsession=50, delta=+8 → new_value = clamp(58, 0, 100) = 58

### 结局判定公式 (Ending Determination)

终章时读取坐标，按优先级匹配：

```
if abyss_triggered AND obsession >= 85:
    ending = "剑覆苍生"
elif obsession < 40 AND worldly >= 60:
    ending = "白衣行天下"
elif obsession >= 60 AND worldly >= 60:
    ending = "孤剑斩世"
elif obsession < 40 AND worldly < 40:
    ending = "大隐于市"
else:
    ending = "孤山留剑"  // 默认/兜底
```

**优先级说明**：魔道结局优先级最高（一旦触发不可逆）。其余 4 个结局按条件匹配，"孤山留剑"作为兜底覆盖中间模糊区域。

### 魔道深渊累积 (Abyss Accumulation)

```
if obsession >= 80 AND node.is_abyss_trigger AND NOT node.abyss_already_counted:
    abyss_counter = min(abyss_counter + 1, 3)
    node.abyss_already_counted = true
if abyss_counter >= 3:
    abyss_triggered = true
```

| 变量 | 类型 | 范围 | 描述 |
|------|------|------|------|
| `abyss_counter` | int | 0–3 | 累积的极端选择次数 |
| `abyss_triggered` | bool | — | 魔道结局是否已解锁 |

**示例**：玩家 obsession=82，在标记为 abyss_trigger 的对话选择中选择了极端选项 → abyss_counter 从 1 变为 2

### 心境区间判定 (Mindset Zone)

NPC 反应和武学获取使用区间判定而非精确值：

```
zone(value) =
    LOW    if value < 30
    NEUTRAL if 30 <= value <= 70
    HIGH   if value > 70
    EXTREME if value >= 85  (仅用于 obsession 轴的魔道检测)
```

## Edge Cases

- **If 心境位移导致坐标在结局区域间频繁切换**：结局判定仅在**终章特定节点**执行，不实时判定。中途的区间变化只影响 NPC 反应和武学获取，不直接改变结局。

- **If 玩家在终章时处于两个结局区域的边界上（如 obsession=40）**：边界值归属于"包含下界"的区域。obsession=40 归入"孤山留剑"区域（因为 < 40 才进入释怀区域）。

- **If 魔道触发后玩家 obsession 降到 85 以下**：`abyss_triggered` 一旦为 true 即不可逆。但结局判定额外要求终章时 obsession ≥ 85 — 如果 obsession 降回，魔道结局不激活，回退到普通 4 结局判定。这提供了一个"悬崖勒马"的最后机会。

- **If 全游戏只有 2 个 abyss 触发点被触碰**：abyss_counter = 2，不满足 ≥ 3 条件，`abyss_triggered` 保持 false。玩家"差一步就堕入魔道"— 这是设计意图。

- **If 对话系统连续发送多个 mindset_shift 事件**：按顺序逐个应用，每次 clamp。不做批量合并 — 中间状态可能触发区间切换和相应的 NPC 反应变化。

- **If 存档损坏导致坐标超出范围**：加载时强制 clamp 到 [0, 100]，abyss_counter clamp 到 [0, 3]。

- **If 玩家在起点章节就做出极端选择**：每章仅允许 2-3 个心境关键选择点（由内容设计控制），且前期选择的 delta 较小（±3 to ±5），防止第一章就到达极端区域。

## Dependencies

| 系统 | 方向 | 依赖性质 | 硬/软 |
|------|------|---------|-------|
| **对话系统** | 心境 depends on 对话 | `mindset_shift` 事件是心境变化的唯一输入 | 硬 |
| **NPC 状态管理** | 双向 | 心境区间影响 NPC 态度；NPC 状态可能触发特定对话 | 软（provisional — NPC 系统未设计） |
| **感情系统** | 感情 depends on 心境 | 心境区间影响感情互动的可用选项 | 软 |
| **武学组合** | 武学 depends on 心境 | 部分武学获取条件依赖心境区间 | 软 |
| **朦胧化 UI** | UI depends on 心境 | 视觉色调渐变需要读取心境坐标 | 软 |
| **主线叙事** | 叙事 depends on 心境 | 终章结局判定读取心境坐标 | 硬 |
| **存档系统** | 双向 | 心境状态需持久化 | 硬 |

## Tuning Knobs

| 参数 | 当前值 | 安全范围 | 增大的效果 | 减小的效果 |
|------|--------|---------|-----------|-----------|
| **初始 obsession** | 50 | 40–60 | 偏向执念起点，需要更多释怀选择才能到达释怀结局 | 偏向释怀起点 |
| **初始 worldly** | 50 | 40–60 | 偏向入世起点 | 偏向出世起点 |
| **普通选择 delta** | ±3 to ±5 | ±1 to ±8 | 每个选择影响更大，更快到达极端 | 需要更多选择才能产生明显变化 |
| **关键选择 delta** | ±10 to ±15 | ±5 to ±20 | 关键时刻的转折感更强 | 关键时刻的影响弱化 |
| **结局区域边界（释怀门槛）** | 40 | 30–50 | 释怀区域更窄，更难进入 | 释怀区域更宽 |
| **结局区域边界（执念门槛）** | 60 | 50–70 | 执念区域更窄 | 执念区域更宽 |
| **魔道 obsession 门槛** | 80 | 75–90 | 更容易触发魔道条件 | 更难触发 |
| **魔道 abyss 所需次数** | 3 | 2–5 | 更难进入魔道 | 更容易进入 |
| **终章魔道 obsession 最低要求** | 85 | 80–95 | "悬崖勒马"的空间更小 | "悬崖勒马"更容易 |
| **每章最大心境关键选择数** | 2-3 | 1-5 | 更多选择点 = 更细腻的心境轨迹 | 更集中，每个选择更重 |

**交互关系**：
- 结局区域边界 × delta 范围：如果 delta 过大且边界过窄，玩家可能在 1-2 个选择内就穿越整个区域
- 魔道门槛 × 关键选择 delta：如果关键选择 delta=15 且门槛=80，从中立 (50) 出发只需 2 个极端选择就到 80

## Visual/Audio Requirements

| 事件 | 视觉反馈 | 音频反馈 | 优先级 |
|------|---------|---------|--------|
| **心境位移发生** | 无直接视觉（隐式 — 通过对话暗示和后续场景色调体现） | 无 | MVP |
| **进入极端执念区间 (>70)** | 场景色调渐冷，暗红/朱砂色微光渐增 | 无（BGM 可能切换为更紧张的变奏） | VS |
| **进入释怀区间 (<30)** | 场景色调渐暖，青绿/水墨感增强 | 无 | VS |
| **魔道边缘 (obsession ≥ 80)** | 画面边缘出现极淡的暗色噪点/裂纹 | 极微弱的低频嗡鸣 | Alpha |
| **魔道觉醒 (abyss_triggered)** | 画面短暂闪为全黑+孤血一滴效果 | 一声利刃出鞘的 SE | Alpha |
| **终幕色调切换** | 整体色调切换到结局对应色板（见结局表） | BGM 切换为结局主题曲 | VS |

**视觉风格原则**：
- 心境变化**从不**产生弹窗、图标或数字提示
- 所有视觉反馈都是渐进的、环境性的 — 色调变化需要 5-10 分钟游戏时间才能被察觉
- 玩家应该在事后（回忆截图、比较早期和后期画面）才意识到"画面一直在变"

> 📌 **Asset Spec** — Visual/Audio requirements 已定义。Art bible 审批后，运行 `/asset-spec system:mindset-system` 生成视觉资产规格。

## UI Requirements

心境系统的核心设计原则是**无 UI**。以下仅列出间接的 UI 需求：

| 信息 | 显示位置 | 更新频率 | 条件 |
|------|---------|---------|------|
| **心境文学暗示** | 对话选项旁（由对话系统管理） | 心境选择出现时 | 对话系统负责渲染 |
| **结局标题** | 终幕画面中央 | 结局判定时 | 仅终幕 |
| **心境视觉图（仅 debug/开发）** | 暂停菜单隐藏选项 | 实时 | 仅 debug build |

**无直接 UI 元素**：没有心境仪表盘、进度条、数字显示或图标。心境的唯一玩家可见表达是通过对话暗示文字、场景色调和 NPC 反应 — 全部由其他系统消费心境数据后各自呈现。

## Acceptance Criteria

1. **GIVEN** 游戏开始，**WHEN** 初始化完成，**THEN** 心境坐标为 (50, 50)，abyss_counter = 0，abyss_triggered = false。

2. **GIVEN** 对话系统触发 `mindset_shift(obsession, +8)`，**WHEN** 当前 obsession = 50，**THEN** obsession 变为 58。

3. **GIVEN** 对话系统触发 `mindset_shift(obsession, +20)`，**WHEN** 当前 obsession = 90，**THEN** obsession 被 clamp 为 100（不超出范围）。

4. **GIVEN** 心境坐标为 (35, 65)，**WHEN** 终章结局判定执行，**THEN** 结局 = "白衣行天下"（obsession < 40 AND worldly ≥ 60）。

5. **GIVEN** abyss_triggered = true AND obsession = 88，**WHEN** 终章结局判定执行，**THEN** 结局 = "剑覆苍生"（魔道结局优先级最高）。

6. **GIVEN** abyss_triggered = true AND obsession = 78，**WHEN** 终章结局判定执行，**THEN** 结局 ≠ "剑覆苍生"（obsession < 85，"悬崖勒马"生效），回退到普通 4 结局判定。

7. **GIVEN** obsession = 82，abyss_counter = 2，**WHEN** 玩家在 abyss_trigger 节点选择极端选项，**THEN** abyss_counter 变为 3，abyss_triggered = true。

8. **GIVEN** obsession = 72（< 80），**WHEN** 玩家在 abyss_trigger 节点选择极端选项，**THEN** abyss_counter 不变（obsession 未达 80 门槛）。

9. **GIVEN** obsession = 75（> 70），**WHEN** NPC 通过 `mindset_check(obsession, >, 70)` 查询，**THEN** 返回 true，NPC 进入"警惕"对话分支。

10. **GIVEN** 任意心境坐标，**WHEN** 玩家界面中任何位置被检查，**THEN** 无数值、仪表盘、进度条或心境相关的直接 UI 元素可见（debug build 除外）。

11. **GIVEN** 存档中的心境状态，**WHEN** 存档被加载，**THEN** obsession、worldly、abyss_counter、abyss_triggered 精确恢复，且值被 clamp 到合法范围。

12. **GIVEN** 游戏进入终章，心境坐标处于两个区域的边界（如 obsession = 45, worldly = 55），**WHEN** 定局选择出现，**THEN** 选项描述反映当前心境倾向，让玩家做出最终方向选择。
