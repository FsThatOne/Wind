# 武学组合

> **Status**: In Design
> **Author**: user + game-designer + systems-designer
> **Last Updated**: 2026-06-02
> **Implements Pillar**: Pillar 1 — 一读定生死（武学是战斗的工具箱）

## Overview

武学组合是玩家的"战斗工具箱构建系统"。玩家在战斗外从所有已学招式中选择 6 套装备进入战斗，同时装备 1 套心法获取被动加成和特殊招式。

招式的强度不由固定品级决定，而由**完整度 × 使用者境界**共同决定——同一招"罗汉拳"，在初窥门径的新手手中只是普通一拳，在炉火纯青的宗师手中却是势不可挡的绝学。这意味着游戏不需要海量招式（总量控制在 25-30 个），而是让每一招随境界提升都有成长感。

不同的招式组合 + 心法搭配 = 不同的战斗风格（纯刚猛、柔克流、巧取流、混合流），让每场战斗都有"我选择了独一无二打法"的身份感。

## Player Fantasy

**"我修的是孤山剑法，专门以刚破巧——但搭配残云心法后，能在关键时刻切换柔系心法招式以柔克刚。这套组合是我想出来的，别人学不会。"**

玩家的武学组合不只是数值优化，更是角色身份的表达。你选择修炼哪门武功、如何搭配，就像武侠小说中主角集百家之长形成自己独特剑道的过程。

更深层的幻想是：**同一招普通的长拳，到了通玄境的武者手中，已经是百招难接的绝学。** 这种"境界决定招式威力"的设定，让玩家感受到的不是"换了更强的招"，而是"我变强了"。

## Detailed Design

### Core Rules

**1. 招式定义**

每个招式有以下固定属性：

| 属性 | 说明 |
|---|---|
| 名称 | 如"罗汉拳"、"断水寒光"、"听风辨形" |
| 体系 | 刚 / 柔 / 巧 |
| 内息消耗 | 0-8 |
| 基础伤害倍率 | 0.6-1.5（相对于体系攻击力的倍率） |
| 特殊效果 | 如"破绽 +1"、"回复内息"、"无视防御 30%" 等（绝学才有） |
| 类型标签 | 攻击 / 防御 / 辅助 |

**2. 招式强度 = 完整度 × 境界缩放**

招式没有固定品级。最终效果由两个维度决定：

- **完整度**（收集进度）：残卷 60% → 拓本 80% → 完本 100%
- **境界缩放**（使用者功力境界）：

| 境界 | 缩放系数 |
|---|---|
| 初学乍练 | ×0.7 |
| 初窥门径 | ×0.8 |
| 登堂入室 | ×0.9 |
| 融会贯通 | ×1.0 |
| 驾轻就熟 | ×1.1 |
| 炉火纯青 | ×1.3 |
| 出神入化 | ×1.5 |
| 登峰造极 | ×1.8 |
| 返璞归真 | ×2.0 |

**最终招式效果 = 基础效果 × 完整度 × 境界缩放**

少量招式标记为"绝学"——这些招式的特殊效果只在**完本**状态下解锁。

**3. 招式获取**

三阶段收集系统：

```
残卷（散落各处）→ 3 张残卷合成拓本 → 修炼时间后成完本
```

- **残卷**：探索/战利品/商店/暗号获取。每个招式最多 3 张残卷
- **拓本**：3 残卷合成。可使用但效果 60%
- **完本**：拓本 + 修炼时间（消耗若干天数的体力）。效果 100%

**4. 装备系统**

- **招式槽**：6 个（至少覆盖刚/柔/巧各 1 个）
- **心法槽**：1 个
- 心法提供：被动属性加成 + 解锁 1-2 个心法专属招式（不占装备槽，作为额外选项出现在战斗中）
- **心法门槛**：部分高级心法有基础属性最低要求

**5. 刚/柔/巧覆盖规则**

装备的 6 个招式必须至少包含刚/柔/巧各 1 个。违反时界面提示：
> "你的武学缺少 X 系招式，将无法应对 X 系攻击——确定要这样出战吗？"

允许玩家强制确认（不强制阻止），但 UI 给出明确警告。

**6. 招式总量控制**

| 体系 | 数量 | 说明 |
|---|---|---|
| 刚 | 8-10 | 偏攻击，高伤害 |
| 柔 | 8-10 | 偏防御/恢复，自带回息 |
| 巧 | 8-10 | 偏机动，高破绽累积 |
| **总计** | **25-30** | 每个体系内有不同功能定位 |

### States and Transitions

招式生命周期：

```
[未发现] → 获取第 1 张残卷 → [残卷收集中]（1/3 或 2/3）
   → 获取第 3 张残卷 → [可合成]
   → 合成 → [拓本]（可使用，效果 ×0.6）
   → 修炼 → [完本]（效果 ×1.0，绝学效果解锁）
```

心法生命周期：

```
[未习得] → 获取心法典籍 → [已习得]
   → 装备 → [激活]（被动生效 + 专属招式可用）
   → 卸下 → [已习得]（被动失效）
```

### Interactions with Other Systems

| 系统 | 接口 | 数据方向 | 说明 |
|---|---|---|---|
| **角色属性** | `GetBaseAttribute(type)` | 属性→武学 | 心法门槛检查 |
| | `ApplyModifiers(mods[])` | 武学→属性 | 心法被动加成写入属性系统 |
| | `GetTotalPower()` → 境界 | 属性→武学 | 确定当前境界缩放系数 |
| **回合制战斗** | `GetEquippedMoves()` | 武学→战斗 | 返回 6 个装备招式 + 心法专属招式 |
| | `GetMoveDetails(id)` | 武学→战斗 | 返回招式的体系/消耗/最终效果 |
| **物品/道具** | `OnFragmentObtained(moveId)` | 道具→武学 | 获取残卷时更新收集进度 |
| **自然日+体力** | `StartTraining(moveId)` | 武学→日历 | 拓本修炼消耗体力和天数 |
| **存档** | `SerializeLoadout()` | 武学→存档 | 序列化装备组合 |

## Formulas

### F1. 最终招式伤害

`move_damage = base_multiplier × attack_for_type × completion × realm_scaling`

| Variable | Type | Range | Description |
|----------|------|-------|-------------|
| base_multiplier | float | 0.6-1.5 | 招式固有伤害倍率 |
| attack_for_type | int | 10-80 | 体系攻击力（来自角色属性） |
| completion | float | 0.6/0.8/1.0 | 完整度（残卷/拓本/完本） |
| realm_scaling | float | 0.7-2.0 | 境界缩放系数 |

**Output Range**: 4-240
**Example**: 基础倍率 1.0，攻击力 35，完本 1.0，炉火纯青 1.3 → 35 × 1.0 × 1.0 × 1.3 = **45.5**

### F2. 心法属性加成

`modifier = xinfa_base_bonus × realm_scaling`

心法的被动加成也受境界影响——高境界时心法效果更强。

### F3. 修炼时间

`training_days = base_days × (1 - inner_power × 0.01)`

| Variable | Type | Range | Description |
|----------|------|-------|-------------|
| base_days | int | 2-5 | 招式基础修炼天数 |
| inner_power | int | 5-50 | 内力属性 |

内力越高修炼越快。最低 1 天。

## Edge Cases

- **如果 6 个装备槽中没有覆盖某个体系**：允许但警告。玩家确认后可以进入战斗。
- **如果拓本招式在战斗中使用**：效果按 60% 计算（已在公式中体现）。界面显示"拓本"标记。
- **如果心法门槛不满足时尝试装备**：禁止装备。提示"力量不足 X 点，无法修炼此心法"。
- **如果获取第 4 张同一招式的残卷**：多余残卷可用于交易或分解（具体由物品系统定义）。
- **如果修炼中途切换心法**：修炼进度保留，不因心法变更而重置。
- **如果返璞归真境界使用初级招式**：境界缩放 ×2.0 仍然生效。"大巧若拙"的设计意图。
- **如果战斗中心法被某种效果"封印"**：心法专属招式变为不可用，心法被动加成暂时失效。装备槽中的 6 个基础招式不受影响。

## Dependencies

| 方向 | 系统 | 依赖类型 | 说明 |
|---|---|---|---|
| 上游（硬） | 角色属性 | 硬 | 境界缩放、心法门槛检查、攻击力来源 |
| 下游（硬） | 回合制战斗 | 硬 | 战斗读取装备招式和心法效果 |
| 下游（软） | 物品/道具 | 软 | 残卷作为可收集道具 |
| 下游（软） | 自然日+体力 | 软 | 修炼消耗体力和天数 |

## Tuning Knobs

| 参数 | 默认值 | 安全范围 | 影响 |
|---|---|---|---|
| `equip_slots` | 6 | 4-8 | 过少→选择空间太窄；过多→管理负担 |
| `xinfa_slots` | 1 | 1-2 | 2 套心法大幅增加构建复杂度 |
| `fragments_per_move` | 3 | 2-5 | 影响收集节奏 |
| `completion_tiers` | [0.6, 0.8, 1.0] | 各项 ±0.1 | 影响拓本 vs 完本的差距感 |
| `realm_scaling_table` | [0.7...2.0] | 见上表 | 影响境界成长感 |
| `training_base_days` | 2-5 | 1-7 | 影响修炼节奏 |
| `total_move_count` | 25-30 | 20-40 | 影响内容量和复杂度 |

## Visual/Audio Requirements

- **招式选择界面**：武学列表以卷轴/书籍风格呈现，残卷/拓本/完本有不同的视觉状态（破损→半旧→完整）
- **心法装备**：心法以太极/八卦图案呈现，激活时发光
- **残卷合成**：3 张残卷汇聚合成拓本的动画 + 纸页翻动音效
- **修炼完成**：完本时发出"悟道"光芒 + 钟声音效
- **绝学解锁**：完本绝学招式时播放特殊金光特效 + 浑厚音效

## UI Requirements

- **武学管理界面**（战斗外）：显示所有已发现/收集中/已学招式，支持拖拽装备到 6 个槽位
- **心法管理界面**：显示已获取心法列表，装备/卸下操作
- **收集进度**：每个招式显示残卷收集进度（0/3, 1/3, 2/3, 拓本, 完本）
- **战斗中招式面板**：显示 6 个装备招式 + 心法专属招式（如有）

## Acceptance Criteria

1. **GIVEN** 玩家有 3 张"罗汉拳"残卷，**WHEN** 选择合成，**THEN** 生成"罗汉拳"拓本，效果为基础的 60%。
2. **GIVEN** 玩家境界为"炉火纯青"，使用完本招式，**WHEN** 计算招式伤害，**THEN** 伤害 = 基础 × 1.0 × 1.3。
3. **GIVEN** 玩家装备 5 个刚系招式和 1 个柔系招式，**WHEN** 进入战斗，**THEN** 显示警告"缺少巧系招式"但允许确认进入。
4. **GIVEN** 心法需要力量 ≥ 20，玩家力量为 15，**WHEN** 尝试装备，**THEN** 禁止装备并提示"力量不足 5 点"。
5. **GIVEN** 拓本招式在战斗中使用，**WHEN** 查看招式面板，**THEN** 该招式显示"拓本"标记。
6. **GIVEN** 玩家装备心法后，**WHEN** 查看战斗招式面板，**THEN** 除 6 个基础槽位外，额外显示 1-2 个心法专属招式。
7. **GIVEN** 境界为"返璞归真"，使用初级招式"罗汉拳"，**WHEN** 计算伤害，**THEN** 缩放系数为 ×2.0。

## Open Questions

1. 修炼时间是否可以通过心境影响？（如"入定"心境缩短修炼天数）
2. 同伴的武学是否可以由玩家自由更换？（待感情系统解决——同伴可能有自己的武学偏好）
3. 是否需要"忘招"机制？（暂定不需要——已学招式永久保留，只是不装备即可）
4. 心法之间是否有冲突关系？（如阳刚心法和阴柔心法不能同时修炼）
