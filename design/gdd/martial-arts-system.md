# 武学组合

> **Status**: In Design
> **Author**: user + game-designer + systems-designer
> **Last Updated**: 2026-06-02
> **Implements Pillar**: Pillar 1 — 一读定生死（武学是战斗的工具箱）

## Overview

武学组合是玩家的"战斗工具箱构建系统"。玩家在战斗外从所有已学招式中选择 6 套装备进入战斗，同时装备 1 套心法获取被动加成和特殊招式。

招式的强度不由固定品级决定，而由**完整度 × 使用者境界**共同决定——同一招"罗汉拳"，在初窥门径的新手手中只是普通一拳，在炉火纯青的宗师手中却是势不可挡的绝学。这意味着游戏不需要海量招式（总量控制在 25-30 个），而是让每一招随境界提升都有成长感。

极少数招式存在**高手批注版本**——某位宗师在原本上留下的毕生心得，令最普通的拳法也能超越顶阶绝学。批注版本通过奇遇获得，全游戏每招仅一份，是武侠世界"只有一个至高存在"的具象化。

不同的招式组合 + 心法搭配 = 不同的战斗风格（纯刚猛、柔克流、巧取流、混合流），让每场战斗都有"我选择了独一无二打法"的身份感。

## Player Fantasy

**"我修的是孤山剑法，专门以刚破巧——但搭配残云心法后，能在关键时刻切换柔系心法招式以柔克刚。这套组合是我想出来的，别人学不会。"**

玩家的武学组合不只是数值优化，更是角色身份的表达。你选择修炼哪门武功、如何搭配，就像武侠小说中主角集百家之长形成自己独特剑道的过程。

更深层的幻想是：**同一招普通的长拳，到了通玄境的武者手中，已经是百招难接的绝学。** 这种"境界决定招式威力"的设定，让玩家感受到的不是"换了更强的招"，而是"我变强了"。

## Detailed Design

### Core Rules

**1. 招式定义**

每个招式有以下固定属性：

| 属性 | 说明 |
|---|---|
| 名称 | 如"罗汉拳"、"断水寒光"、"听风辨形"——所有招式均采用武林正名，无论类别皆有文化尊严 |
| 体系 | 刚 / 柔 / 巧 |
| **类别** | **普通 / 高级 / 绝学**（决定成长路径，见下节；UI 不展示此标签） |
| 内息消耗 | 0-8 |
| 基础伤害倍率 | 普通 0.6-1.0 / 高级 1.0-1.3 / 绝学 1.3-1.5 |
| **触发条件** | **特殊效果的触发时机**。所有招式均有，但条件宽窄因类别而异：普通武学条件最为严苛（如"本回合第 2 次克制同一目标"），高级武学条件居中，绝学条件最为宽泛（如"命中时无条件触发"）。条件宽窄是体感"稀有度"的来源，而非颜色。 |
| **特殊效果** | 触发后生效的额外效果（如"破绽 +2"、"无视防御 25%"、"回复内息 2"）。所有招式均有；绝学的特殊效果在完本后解锁。 |
| 类型标签 | 攻击 / 防御 / 辅助 |

**2. 招式强度 = 完整度 × 境界缩放 × 触发价值**

招式没有固定品级，也没有颜色层级。玩家对一招的取舍标准是：

> **触发条件的泛用性 × 触发后的效果强度**

- **普通武学**：条件严苛但效果鲜明——针对特定战术有奇效，通用场合偏弱。"罗汉拳：本回合第 2 次克制同一目标触发破绽 +2"——遇上好机会就是神招，遇不上只是一拳。
- **高级武学**：条件居中，效果较强——比普通武学更容易发挥，但仍有战术门槛。
- **绝学**：条件最宽（常为无条件或极易满足），效果改变战局——真正的"随手就能用"。但绝学需要残卷收集，完本后才解锁全部效果。

这意味着：**一本条件严苛的普通武学，搭配正确的战术可以压制绝学。** 玩家不是在比谁的武学颜色更高，而是在设计自己的战术路线。

最终输出效果由两个维度决定：

- **完整度**（收集/修炼进度）：五层，见下节
- **境界缩放**（使用者功力境界）：

| 境界 | 缩放系数 |
|---|---|
| 初学乍练 | ×0.7 |
| 初窥门径 | ×0.8 |
| 登堂入室 | ×0.9 |
| 融会贯通 | ×1.0 |
| 驾轻就熟 | ×1.1 |
| 炉火纯青 | ×1.3 |
| 出神入化 | ×1.5 |
| 登峰造极 | ×1.8 |
| 返璞归真 | ×2.0 |

**最终招式效果 = 有效基础倍率 × 攻击力 × 完整度 × 境界缩放**

少量招式标记为"绝学"——这些招式的特殊效果只在**完本及以上**状态下解锁。

**3. 招式获取——两套成长路径**

招式按类别走不同的成长路径，外加一条全类别适用的奇遇路径。

---

**路径 A：普通武学（习得即满）**

普通武学无进度层级。习得即为满状态（completion = 1.00），可直接出战，无需修炼时间。

| 状态 | completion | 获取方式 |
|------|-----------|---------|
| **已习得** | 1.00 | 初始携带 / 师傅传授 / NPC 处学习 / 商店购买 |

---

**路径 B：高级武学 & 绝学（残卷收集，4 层）**

| 层 | 名称 | completion | 获取方式 |
|----|------|-----------|---------|
| 1 | **残卷** | 0.55 | 探索/战利品/暗号获取。**获得 1 张即可出战** |
| 2 | **拓本** | 0.72 | 3 张残卷合成 |
| 3 | **完本** | 0.88 | 拓本 + 修炼时间。高级特效解锁；绝学特效 v1 解锁 |
| 4 | **真传** | 1.00 | 叙事事件专属：师承传授、前辈临终口诀、秘境真本。绝学特效 v2 升阶 |

绝学与高级武学走同一路径，但残卷散落更稀、特效更强。

---

**路径 C：批注版本（奇遇，任意类别）**

部分招式存在**高手批注版本**——宗师在原本上留下的毕生心得，令任何类别的武学都能突破上限。

| 属性 | 说明 |
|------|------|
| 适用类别 | 普通 / 高级 / 绝学均可，由武学数据库逐一标注（待后续设计） |
| 获取方式 | **奇遇专属**：古墓秘藏、击败传奇人物、前辈遗物 |
| 稀缺性 | 全游戏每个招式仅存在 **1 份**，不可复制 |
| 效果 | **三重效果**：① 完整度视同满（completion=1.00）；② **触发条件放宽**（条件变得更宽泛/更易满足）；③ **特殊效果增强**（效果数值提升或质量升阶）。批注不是通用倍率——它是对这一招**具体智慧的传授**，改变的是这招"怎么用"和"用了有多强" |
| annotation_bonus | 每份批注包含三个组件（由武学数据库逐一定义）：`condition_override`（新触发条件，更宽泛）、`effect_override`（效果的强化版本）、`annotation_mult`（基础伤害倍率加成系数，与 `base_multiplier` 成反比，普通武学取高端使其可与绝学竞技） |
| 数值 | `effective_base_multiplier = base_multiplier × annotation_mult`，超过正常 `base_multiplier` 上限 |

**批注示例（罗汉拳 → 批注版）**：

| 项目 | 原版 | 批注版 |
|------|------|--------|
| 触发条件 | 本回合第 2 次克制同一目标 | 本回合第 1 次克制即触发 |
| 特殊效果 | 破绽 +2 | 破绽 +3 |
| base_multiplier | 0.7 | 0.7 × 1.8 = 1.26（超越未批注高级武学） |

> **设计意图**：批注版是宗师对这一招"活法"的具象传授——条件变宽意味着这位宗师找到了更省力的触发时机，效果变强意味着理解更深。不是"更快满级"，而是"这招在你手里已经不是原来那招"。

**4. 装备系统**

- **招式槽**：6 个（至少覆盖刚/柔/巧各 1 个）
- **心法槽**：1 个
- 心法提供：被动属性加成 + 解锁 1-2 个心法专属招式（不占装备槽，作为额外选项出现在战斗中）
- **心法门槛**：部分高级心法有基础属性最低要求

**5. 刚/柔/巧覆盖规则**

装备的 6 个招式必须至少包含刚/柔/巧各 1 个。违反时界面提示：
> "你的武学缺少 X 系招式，将无法应对 X 系攻击——确定要这样出战吗？"

允许玩家强制确认（不强制阻止），但 UI 给出明确警告。

**6. 招式总量控制**

| 体系 | 数量 | 说明 |
|---|---|---|
| 刚 | 8-10 | 偏攻击，高伤害 |
| 柔 | 8-10 | 偏防御/恢复，自带回息 |
| 巧 | 8-10 | 偏机动，高破绽累积 |
| **总计** | **25-30** | 每个体系内有不同功能定位 |

### States and Transitions

招式生命周期（三条路径）：

```
普通武学（路径 A）：
[未习得] → 习得 → [已习得] completion=1.00（即时可出战，无进度）

高级武学 / 绝学（路径 B）：
[未发现]
  → 获得第 1 张残卷 → [残卷] completion=0.55（可出战；2/3 张时仍按 0.55）
  → 凑齐 3 张 → [可合成]
  → 合成 → [拓本] completion=0.72
  → 修炼时间 → [完本] completion=0.88，高级特效 / 绝学特效 v1 解锁
  → 叙事事件 → [真传] completion=1.00，绝学特效 v2 升阶

批注版本（路径 C，任意类别、任意阶段触发）：
[任意状态] ──奇遇──→ [批注版] completion=1.00，base_multiplier 替换为批注专属值
                       ↑ 直接覆盖当前进度，成为该招式最终形态
```

心法生命周期：

```
[未习得] → 获取心法典籍 → [已习得]
   → 装备 → [激活]（被动生效 + 专属招式可用）
   → 卸下 → [已习得]（被动失效）
```

### Interactions with Other Systems

| 系统 | 接口 | 数据方向 | 说明 |
|---|---|---|---|
| **角色属性** | `GetBaseAttribute(type)` | 属性→武学 | 心法门槛检查 |
| | `ApplyModifiers(mods[])` | 武学→属性 | 心法被动加成写入属性系统 |
| | `GetTotalPower()` → 境界 | 属性→武学 | 确定当前境界缩放系数 |
| **回合制战斗** | `GetEquippedMoves()` | 武学→战斗 | 返回 6 个装备招式 + 心法专属招式 |
| | `GetMoveDetails(id)` | 武学→战斗 | 返回招式的体系/消耗/最终效果 |
| **物品/道具** | `OnFragmentObtained(moveId)` | 道具→武学 | 获取残卷时更新收集进度 |
| **自然日+体力** | `StartTraining(moveId)` | 武学→日历 | 拓本修炼消耗体力和天数 |
| **存档** | `SerializeLoadout()` | 武学→存档 | 序列化装备组合（含各招式层级、批注版标记与 annotation_mult） |

## Formulas

### F1. 最终招式伤害

`move_damage = effective_base_multiplier × attack_for_type × completion × realm_scaling`

| Variable | Type | Range | Description |
|----------|------|-------|-------------|
| effective_base_multiplier | float | 0.6-1.5（普通）/ 超过 1.5（批注版） | 招式有效伤害倍率；批注版 = `base_multiplier × annotation_mult` |
| attack_for_type | int | 10-80 | 体系攻击力（来自角色属性） |
| completion | float | 1.00（普通，固定）或 0.55/0.72/0.88/1.00（高级/绝学） | 由招式类别决定；批注版视同 1.00 |
| realm_scaling | float | 0.7-2.0 | 境界缩放系数 |

**Output Range（普通）**: 4-240  
**Output Range（批注版）**: 可超过 240，上限由 annotation_mult 决定  
**Example（真传）**: 倍率 1.0，攻击力 35，真传 1.0，炉火纯青 1.3 → **45.5**  
**Example（批注版，入门武学）**: 原倍率 0.7，annotation_mult=1.8，攻击力 35，炉火纯青 1.3 → 35 × (0.7×1.8) × 1.0 × 1.3 = **57.3**（超越未批注的高级招式）

### F2. 心法属性加成

`modifier = xinfa_base_bonus × realm_scaling`

心法的被动加成也受境界影响——高境界时心法效果更强。

### F3. 修炼时间

`training_days = base_days × (1 - inner_power × 0.01)`

| Variable | Type | Range | Description |
|----------|------|-------|-------------|
| base_days | int | 2-5 | 招式基础修炼天数 |
| inner_power | int | 5-50 | 内力属性 |

内力越高修炼越快。最低 1 天。

## Edge Cases

- **如果 6 个装备槽中没有覆盖某个体系**：允许但警告。玩家确认后可以进入战斗。
- **如果普通武学被习得**：completion=1.00，无层级标记，无需任何后续操作。
- **如果高级/绝学残卷状态招式在战斗中使用**：completion=0.55，界面显示"残卷"标记。
- **如果高级/绝学拓本招式在战斗中使用**：completion=0.72，界面显示"拓本"标记。
- **如果高级/绝学完本招式在战斗中使用**：completion=0.88，高级特效 / 绝学效果 v1 可触发。
- **如果真传招式在战斗中使用**：completion=1.00，绝学效果 v2 可触发，界面显示金色"真传"标记。
- **如果批注版招式在战斗中使用**：completion=1.00，base_multiplier 使用批注专属值，界面显示专属批注来源标记（如"如净大师批注"）。
- **如果玩家持有某招式的进度（如完本），再发现该招式批注版本**：批注版直接覆盖完本进度，完本状态不保留。批注版是终态。
- **如果某招式不存在批注版本**：真传为该招式最高形态，不显示任何批注入口。
- **如果心法门槛不满足时尝试装备**：禁止装备。提示"力量不足 X 点，无法修炼此心法"。
- **如果获取第 4 张同一招式的残卷**：多余残卷可用于交易或分解（具体由物品系统定义）。
- **如果修炼中途切换心法**：修炼进度保留，不因心法变更而重置。
- **如果返璞归真境界使用初级批注版招式**：境界缩放 ×2.0 与批注倍率同时生效，为设计允许的最高伤害。
- **如果战斗中心法被某种效果"封印"**：心法专属招式变为不可用，心法被动加成暂时失效。装备槽中的 6 个基础招式不受影响。

## Tuning Knobs

| 参数 | 默认值 | 安全范围 | 影响 |
|---|---|---|---|
| `equip_slots` | 6 | 4-8 | 过少→选择空间太窄；过多→管理负担 |
| `xinfa_slots` | 1 | 1-2 | 2 套心法大幅增加构建复杂度 |
| `fragments_per_move` | 3 | 2-5 | 影响收集节奏 |
| `completion_common` | 1.00 | 固定 | 普通武学习得即满，不可调整 |
| `completion_tiers_advanced` | [0.55, 0.72, 0.88, 1.00] | 各项 ±0.05 | 高级/绝学四层差距感；真传须明显强于完本 |
| `annotation_mult_range` | [1.2, 1.8] | [1.1, 2.0] | 批注基础倍率范围；普通武学批注取高端（与绝学竞技），绝学取低端（本已强大）；与 `base_multiplier` 成反比 |
| `annotation_condition_improvement` | 显著放宽 | 由数据库定义 | 批注版触发条件的改善程度；通常从"第2次克制"→"第1次克制"，或从"命中时50%概率"→"无条件" |
| `annotation_effect_improvement` | 效果+50%~100% | 由数据库定义 | 批注版特殊效果数值的提升幅度；如破绽+2→+3，防御减少20%→35% |
| `realm_scaling_table` | [0.7...2.0] | 见上表 | 影响境界成长感 |
| `training_base_days` | 2-5 | 1-7 | 影响修炼节奏 |
| `total_move_count` | 25-30 | 20-40 | 影响内容量和复杂度 |

## Visual/Audio Requirements

- **招式选择界面**：武学列表以卷轴/书籍风格呈现。体系通过**色调**区分（刚系暖赤金、柔系玄青冷色、巧系烟灰中性）；**不使用品质颜色**（无绿蓝紫金红）。收集层级通过书册外观传达：残卷（破损卷轴）→ 拓本（完整但泛黄）→ 完本（装裱精良）→ 真传（金印封面）→ 批注版（另见下条）
- **批注版外观**：书页呈现泛黄古卷质感，边角有朱砂批注笔迹，整体有别于所有普通层级——让玩家一眼认出这是神物
- **心法装备**：心法以太极/八卦图案呈现，激活时发光
- **残卷合成**：3 张残卷汇聚合成拓本的动画 + 纸页翻动音效
- **修炼完成**：完本时发出"悟道"光芒 + 钟声音效
- **真传获得**：专属叙事演出（由叙事系统触发），传授场景 + 独特音效
- **批注版发现**：奇遇专属全屏演出，书册自动翻页 + 批注字迹显现动画；效果应比境界突破更震撼

## UI Requirements

**设计原则：数字与条件说话，颜色只传达体系**

游戏中不使用品质颜色（绿/蓝/紫/金/红）标注武学高下。武学的价值由玩家通过条件和数值自行判断。颜色仅用于区分体系（刚/柔/巧），不传递任何稀有度信息。

- **武学管理界面**（战斗外）：
  - 每张武学卡片显示：**名称**、体系图标（体系色调）、内息消耗、招式威力（×倍率数值）
  - **触发条件与特殊效果**必须在卡片上直接可见（不折叠），是玩家做选择的核心依据
  - 高级/绝学武学显示**收集进度条**（0/3残卷→拓本→完本→真传）；普通武学显示"已习得"文字，**无进度条**（进度条本身是稀有度信号，无需颜色）
  - 批注版以**古卷纸张质感 + 朱砂批注笔迹**视觉区分（不是特殊颜色，而是质感处理）
  - 支持拖拽装备到 6 个槽位
- **心法管理界面**：显示已获取心法列表，装备/卸下操作
- **战斗中招式面板**：
  - 显示 6 个装备招式 + 心法专属招式（如有）
  - 每个招式简要显示：**体系图标 + 内息消耗 + 触发条件的图标提示**（战斗中一眼可读）
  - 批注版招式有独特边框纹路，区别于所有普通层级
- **快速比较**：玩家选中两招时，界面并排显示条件、效果和倍率数值，不标注优劣，由玩家判断

📌 **UX Flag — 武学组合**：Pre-Production 阶段运行 `/ux-design` 为武学管理界面创建 UX 规格。

## Acceptance Criteria

**普通武学（路径 A）**

1. **GIVEN** 玩家习得普通武学"罗汉拳"，**WHEN** 进入战斗，**THEN** 该招式以 completion=1.00 直接可出战，无任何进度门槛。

**高级武学 / 绝学（路径 B）**

3. **GIVEN** 玩家获得第 1 张高级招式残卷，**WHEN** 进入战斗，**THEN** 该招式以残卷状态（completion=0.55）可出战，界面显示"残卷"标记。
4. **GIVEN** 玩家有 3 张同一高级招式残卷，**WHEN** 选择合成，**THEN** 生成拓本（completion=0.72），界面标记更新为"拓本"。
5. **GIVEN** 玩家境界为"炉火纯青"，使用真传招式（completion=1.00），**WHEN** 计算招式伤害，**THEN** 伤害 = base_multiplier × attack × 1.0 × 1.3。

**批注版本（路径 C）**

6. **GIVEN** 玩家拥有某招式的任意版本（习练/完本等），**WHEN** 触发奇遇发现该招式批注版，**THEN** 批注版直接替换当前状态，当前进度不保留。
7. **GIVEN** 玩家持有批注版普通招式（原 base_multiplier=0.7，annotation_mult=1.8），境界炉火纯青，**WHEN** 计算伤害，**THEN** effective_base = 0.7×1.8=1.26，高于同境界下未批注的高级招式。
8. **GIVEN** 某招式不存在批注版，**WHEN** 玩家查看该招式详情，**THEN** 界面不显示批注相关入口，真传（或精通）为最高层。
9. **GIVEN** 玩家持有批注版罗汉拳（condition_override="第1次克制即触发"），**WHEN** 第1次克制命中对手，**THEN** 特殊效果（如破绽+3）立即触发，而未批注版本同样操作下不触发。
10. **GIVEN** 玩家持有原版罗汉拳（condition="第2次克制触发"），**WHEN** 本回合第1次克制命中，**THEN** 特殊效果不触发；第2次克制命中时触发。

**UI 无品质颜色**

11. **GIVEN** 玩家查看武学管理界面，**WHEN** 界面加载，**THEN** 所有招式卡片的颜色仅体现体系（刚/柔/巧），不体现稀有度等级；高级/绝学招式通过进度条（非颜色）传达"仍在收集"状态。
12. **GIVEN** 玩家查看任意武学的详情，**WHEN** 界面展开，**THEN** 触发条件和特殊效果直接可见（不折叠），倍率以数字明确展示。

**通用规则**

9. **GIVEN** 玩家装备 5 个刚系招式和 1 个柔系招式，**WHEN** 进入战斗，**THEN** 显示警告"缺少巧系招式"但允许确认进入。
10. **GIVEN** 心法需要力量 ≥ 20，玩家力量为 15，**WHEN** 尝试装备，**THEN** 禁止装备并提示"力量不足 5 点"。
11. **GIVEN** 玩家装备心法后，**WHEN** 查看战斗招式面板，**THEN** 除 6 个基础槽位外，额外显示 1-2 个心法专属招式。
12. **GIVEN** 境界为"返璞归真"，使用批注版普通招式，**WHEN** 计算伤害，**THEN** realm_scaling=2.0 与 annotation_mult 同时生效，输出为设计允许的最高值。

## Open Questions

1. 修炼时间是否可以通过心境影响？（如"入定"心境缩短修炼天数）
2. 同伴的武学是否可以由玩家自由更换？（待感情系统解决——同伴可能有自己的武学偏好）
3. 是否需要"忘招"机制？（暂定不需要——已学招式永久保留，只是不装备即可）
4. 心法之间是否有冲突关系？（如阳刚心法和阴柔心法不能同时修炼）
