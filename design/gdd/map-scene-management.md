# 地图 / 场景管理 (Map / Scene Management)

> **Status**: Designed
> **Author**: user + agents
> **Last Updated**: 2026-06-04
> **Implements Pillar**: Pillar 1 (江湖是活的), Pillar 3 (武侠味先于游戏味)

## Overview

地图/场景管理系统是《风止》的空间骨架 — 负责 18 个命名地点的加载、切换、解锁和环境基调控制。它既是技术基础设施（所有需要"玩家身处某地"的系统都依赖它），也是玩家"行走江湖"空间节奏的塑造者。

玩家不会意识到"场景管理"的存在，但会自然地感受到：从江南水乡走入塞北风雪时色调渐冷、从客栈出发时面对三条分叉路径的选择感、解锁新区域时"江湖又大了一片"的探索欲。系统通过线性骨架（主线推进解锁章节区域）+ 呼吸期开放（章节内自由移动）的结构，在"不做开放世界"的前提下提供有密度的空间体验。

架构上采用数据驱动的场景连通图和标准化出入口接口，为未来扩展预留空间 — 增加新场景只需增加配置条目，不改动系统逻辑；后续版本可在此基础上升级为区域无缝地图而无需重写核心。

核心职责：
1. **场景加载与切换** — 管理场景资源的异步加载、卸载和过渡动画
2. **区域解锁与访问控制** — 根据主线进度和条件解锁新区域
3. **章节色调控制** — 根据当前章节和心境状态调控场景的视觉基调
4. **空间连接图** — 定义场景之间的连通关系和移动规则
5. **呼吸期区域** — 在主线节点之间提供可自由移动的区域集合

## Player Fantasy

**"我不知道下一个路口通往哪里，但我知道江湖比我现在所见的更大 — 而每一次踏入新地方，都可能改变这趟旅途的走向。"**

场景管理对玩家完全透明，但它塑造的空间感让玩家始终怀揣武侠式的探索期待：

**路途即叙事** — 当玩家从客栈出发，面前的路不只是地理移动，而是"选择去追哪条线索"的起点。三条分叉代表三个未完成的故事。哪怕只是走到隔壁酒楼，那也是"我选择了这里而非那里"的微小决策。

**新地方 = 新可能** — 每次主线推进解锁新区域时，玩家感受到的不是"地图变大了"，而是"又多了几个想去看看的地方"。18 个地点各有独特的视觉性格和氛围，确保每次踏入新场景都有"翻开新一章"的新鲜感。

**时节有痕** — 江湖不是静止的画卷。中原的秋叶、江南的春雨、冬日冰河上的垂钓老翁 — 季节与天气在玩家不刻意留意时为世界注入"时间在流逝"的真实感。你上次来这条街还是夏天，如今已是初雪。

**色调即心境** — 从江南的暖到塞外的寒，空间的视觉变化在潜意识里强化旅途的情感弧线 — 复仇之路越走越远，色彩越走越冷。

**支柱对齐**：
- **Pillar 1**（江湖是活的）— 季节流转、天气变幻、场景随时间改变，世界有呼吸
- **Pillar 3**（武侠味先于游戏味）— 不做导航标记和任务罗盘，用"问路""听说"来引导探索

## Detailed Design

### Core Rules

**1. 场景层级结构**

系统管理两个空间层级：

**地点（Location）**— 大地图上的一个标记点。玩家在大地图上看到和移动到的单位。
- 每个地点包含 1 到多个**场景（Scene）**
- 地点有唯一入口场景（从大地图进入时玩家出现的场景）
- 地点有 0 到多个外围出口（离开时回到大地图）

**场景（Scene）**— 玩家实际活动的游戏空间。
- 同一地点内的场景通过出口点直连（走到北出口 → 直接进入北面场景）
- 跨地点的场景不能直连 — 必须经过大地图

举例：
- "柳家镇"是一个地点（大地图上一个标记）
- 镇内有：镇口、集市、客栈、镇北树林 — 都是场景
- 从镇口走北出口 → 直接进入镇北树林（不触发大地图）
- 从镇口走南出口 → 离开柳家镇 → 进入大地图

**2. 场景连接图（数据驱动）**

所有场景间的连通关系存储在一张**连接图配置表**中，不硬编码在代码里。

连接分两类：
- **地点内连接（internal）**：场景 A ↔ 场景 B，走到出口点直接切换
- **地点外出口（exit_to_map）**：场景 → 大地图，触发大地图展开

每条连接记录包含：
- `from_scene`：起始场景标识
- `to_scene`：目标场景标识（地点内连接）或 `"world_map"`（外出口）
- `exit_point`：起始场景内的出口位置标识
- `entry_point`：目标场景内的入口位置标识
- `connection_type`：`internal` / `exit_to_map`
- `unlock_conditions`：解锁条件列表（可为空 = 始终开放）
- `transition_type`：过渡类型（`fade` / `ink_wash`）
- `bidirectional`：是否双向（大部分为真，少数剧情单向门为假）

设计原则：
- 新增场景或连接 = 新增配置条目，不改代码
- 连接图支持条件动态变化（如某事件后新开一条密道）
- 删除连接 = 将条件设为永不满足，不实际删除记录

**3. 场景加载与切换**

场景切换流程：

```
玩家触发出口 → 锁定玩家输入 → 播放过渡动画（前半）→
卸载当前场景 → 异步加载目标场景 →
将玩家放置在目标入口点 → 播放过渡动画（后半）→ 解锁玩家输入
```

过渡类型：
- **淡入淡出（fade）**：默认。画面淡黑 → 加载 → 淡出。总时长约 0.8-1.2 秒。
- **水墨晕染（ink_wash）**：重要剧情转场。水墨从屏幕边缘晕开覆盖全屏 → 加载 → 水墨散去。总时长约 1.5-2.5 秒。

异步加载规则：
- 如果目标场景已预加载完毕，过渡动画前半播完后立即切换
- 如果加载未完成，在全黑/全墨状态等待（玩家看不到等待）
- 预加载策略：当玩家进入某场景时，预加载该场景所有相邻场景

**4. 区域解锁与访问控制**

每个地点有一个 `access_state`：
- **locked（锁定）**：玩家不知道这个地方的存在，大地图上不显示
- **known（已知）**：大地图上显示为灰色图标，不可前往
- **unlocked（已解锁）**：可自由前往

状态转换由主线叙事系统通过事件驱动：
- `location_revealed(id)` → locked 变为 known
- `location_unlocked(id)` → known 变为 unlocked
- 部分地点可以从 locked 直接跳到 unlocked

呼吸期机制：
- 每个主线节点完成后，进入呼吸期
- 呼吸期内，当前章节所有已解锁地点可自由来往
- 主线下一节点的触发条件可能包含"到达特定场景"或"完成特定支线"

**5. 季节与天气子模块**

**5a. 季节系统**

- 四季循环：春→夏→秋→冬，每季 30 个游戏日，一年 = 120 天
- 季节状态由自然日系统推进，场景管理系统订阅 `season_changed(new_season)` 事件
- 季节对场景的影响按区域分级：

| 区域 | 季节影响程度 | 表现方式 |
|------|------------|---------|
| 塞北/雪山 | 极低 | 常年积雪，四季几乎无视觉差异 |
| 江南 | 低 | 四季如春的基底，微调：春有细雨、夏日蝉鸣、秋叶点缀、冬加一层薄霜 |
| 中原 | 高 | 明显四季色调变化：春绿、夏浓、秋黄红、冬灰白 |
| 戈壁/孤城 | 中 | 昼夜温差大于季节差；冬季多风沙，夏季热浪 |

- 每个场景配置一个 `season_sensitivity` 等级（none / low / medium / high），决定季节切换时需加载的视觉变体数量

**5b. 天气系统**

- 天气状态：晴、多云、小雨、大雨、雪、雾、风沙（共 7 种）
- 天气不由玩家控制，按以下规则每日刷新：
  - 当前季节决定天气概率池（如冬天雪概率高、夏天大雨概率高）
  - 当前区域过滤不合理天气（如塞北不下雨只下雪；江南不起风沙）
  - 特殊剧情可强制指定天气（如 boss 对峙时暴雨）
- 天气持续时间：1-3 天随机，剧情强制天气持续到剧情事件结束
- 天气对玩家的影响：
  - 纯视觉 + 音效（雨声、风声、雪花粒子）
  - 背景人物行为变化（下雨时撑伞/躲雨、下雪时缩颈快走）
  - 轻度影响奇遇触发条件（如"冰上垂钓老翁"需要：冬天 + 该场景有河 + 天气为晴/多云）

**5c. 时辰系统**

一个游戏日 = 12 时辰：

| 序号 | 时辰 | 现实对应 | 光照分类 |
|------|------|---------|---------|
| 1 | 子时 | 23:00-01:00 | 夜 |
| 2 | 丑时 | 01:00-03:00 | 夜 |
| 3 | 寅时 | 03:00-05:00 | 晨 |
| 4 | 卯时 | 05:00-07:00 | 晨 |
| 5 | 辰时 | 07:00-09:00 | 日 |
| 6 | 巳时 | 09:00-11:00 | 日 |
| 7 | 午时 | 11:00-13:00 | 日 |
| 8 | 未时 | 13:00-15:00 | 日 |
| 9 | 申时 | 15:00-17:00 | 日 |
| 10 | 酉时 | 17:00-19:00 | 昏 |
| 11 | 戌时 | 19:00-21:00 | 昏 |
| 12 | 亥时 | 21:00-23:00 | 夜 |

- 光照分类影响场景变体：日（5 时辰）、晨（2 时辰）、昏（2 时辰）、夜（3 时辰）
- 时辰切换时发送 `shichen_changed(new_shichen)` 事件
- 背景人物、商铺开关、NPC 出没均可绑定时辰条件

**5d. 季节/天气/时辰的数据接口**

对外暴露：
- `get_current_season()` → 春/夏/秋/冬
- `get_current_weather()` → 7 种之一
- `get_season_day()` → 当前季节内第几天（1-30）
- `get_current_shichen()` → 当前时辰（子/丑/寅/卯/辰/巳/午/未/申/酉/戌/亥）
- `get_light_category()` → 当前光照分类（日/晨/昏/夜）
- `is_weather_forced()` → 是否为剧情强制天气

其他系统通过查询这些接口来决定条件逻辑。

**6. 章节色调控制**

章节色调与季节独立运作。章节色调体现旅途的情感弧线，季节体现时间流逝。两者叠加。

| 章节 | 基础色调 | 视觉风格关键词 |
|------|---------|--------------|
| 起点·落尘谷 | 墨黑山影 + 白衣 | 肃杀、孤寂、强对比 |
| 江南 | 暖色调、低饱和绿/青 | 温润、细腻、有生气 |
| 北方 | 灰冷过渡 | 萧索、苍茫、颜色渐失 |
| 塞外 | 雪白+墨黑+朱砂三色 | 极致冷峻、高对比 |
| 终幕 | 随结局心境变化 | 见下 |

终幕色调规则（由心境双轴系统输出决定）：
- 白衣行天下（释怀+入世）= 江南回暖色
- 孤剑斩世（执念+入世）= 朱红压顶
- 大隐于市（释怀+出世）= 烟雨灰蓝
- 风止剑鸣（执念+出世）= 雪白墨黑
- 剑覆苍生（魔道）= 全黑 + 一点孤血红

色调切换时机：进入新章节的第一个场景时，通过渐变过渡（约 2-3 秒内）切换到新章节色调。

实现方式：每个场景配置基础调色板（色相、饱和度、明度偏移），由章节色调参数 + 季节修正叠加计算最终渲染参数。

**7. 大地图**

大地图是场景之间的旅行层，玩家在大地图上操控主角标记移动，到达特定地点后可进入该场景。

**7a. 进出大地图**

- 进入大地图：玩家走到某场景的"外围出口"（connection_type = exit_to_map）→ 大地图展开，标记在对应地点
- 退回当前场景：在大地图上选择当前所在地点 → 返回场景
- 进入新地点：移动标记到达目标地点 → 过渡动画 → 加载该地点的入口场景

**7b. 大地图操作**

- 玩家操控一个主角大头针（或缩小立绘）在地图上移动
- 移动方式：点击目标位置 / 按住方向键持续移动
- 地图内无空气墙 — 可自由穿越山川河流（武侠角色轻功翻山渡水合理）
- 地图边界设空气墙 — 海岸线、地图四边为不可通行边界
- 移动有实时视觉反馈（标记沿路径移动）

**7c. 时间与体力消耗**

旅行时间和体力按移动距离实时计算（参考《大侠立志传》）：
- 系统将大地图网格化，每移动 1 格实时消耗：
  - 时间：0.01 游戏日（≈ 0.12 时辰）
  - 体力：0.2 点
- 实时扣除 — 每格移动后立即推进时间和扣减体力
- 移动可能跨越时辰/日/季节边界，逐格检查并触发对应事件
- 触发奇遇时暂停时间和体力消耗

速度修正：
- 体力 > 0：正常移动速度
- 体力 = 0：移动速度降低 50%（等效每格消耗 0.02 天），不再扣除体力
- 体力不会降为负数

**7d. 大地图奇遇**

- 地图上存在隐藏触发点（玩家看不到），当标记移动到该位置时触发奇遇事件
- 奇遇触发受条件约束：季节、天气、时辰、主线进度、心境值、随机概率
- 奇遇类型：战斗遭遇、NPC 对话事件、发现物品/线索、自然景观描写
- 同一触发点可配置多个奇遇，按优先级和条件选取

**7e. 不可前往区域的角色化提示**

- 锁定区域（locked/known 但未 unlocked）在地图上可见但标记无法进入
- 标记靠近时触发主角内心独白（角色化拒绝理由），例如：
  - "大仇未报，不是闲逛的时候。"
  - "眼下最要紧的事是找到白苓姑娘。"
  - "再过三天武林大会就要开始了，得抓紧闭关。"
- 每个锁定区域配置多条独白文本，根据当前主线状态选取最贴切的
- 独白文本的数据结构复用对话系统的 InnerMonologue 节点格式

**7f. 场景内地图查看**

- 玩家在场景内可打开地图（只读模式）
- 只读模式：只能查看当前位置和已知地点分布，不能点选交互、不能移动标记
- 用途：让玩家确认方位和规划下一步

**8. 驿站系统**

驿站是大地图上的快速旅行节点，仅设置在大城市/大门派附近（如洛阳、长安、少林寺、武当山等）。小村庄、小门派、野外地点无驿站。

**8a. 使用条件**

- 玩家必须身处某个已解锁的驿站才能使用
- 只能传送到其他已解锁的驿站（首次步行到达后解锁）
- 需要支付费用

**8b. 驿站效果**

- 旅行时间 = 步行时间 × 0.5（即 `距离(格) × 0.01 × 0.5`）
- 体力消耗 = 0
- 费用 = base_fee + distance_fee × 距离(格)
- 传送过程有过渡动画（玩家体感接近瞬移）
- 传送过程中不触发大地图奇遇、不推进时辰事件（到达后一次性推进时间）

**8c. 驿站数据**

每个驿站配置：
- `station_id`：唯一标识
- `location_id`：所属地点
- `position`：大地图坐标
- `unlocked`：是否已解锁（默认 false，首次到达后 true）

### States and Transitions

系统有两个状态机：场景状态和大地图状态。

#### 场景状态机

| 状态 | 进入条件 | 退出条件 | 行为 |
|------|---------|---------|------|
| **Active** | 场景加载完成，过渡动画结束 | 玩家触发出口 / 剧情强制切换 | 正常游戏运行，所有系统活跃 |
| **TransitionOut** | 出口触发 | 过渡动画前半结束 | 锁定玩家输入，播放过渡动画前半（淡黑/水墨覆盖） |
| **Loading** | 过渡前半完成 | 目标场景加载完毕 | 卸载当前场景，异步加载目标场景。画面保持全黑/全墨 |
| **TransitionIn** | 目标场景就绪 | 过渡动画后半结束 | 玩家放置在入口点，播放过渡动画后半（黑→亮 / 墨散） |

#### 大地图状态机

| 状态 | 进入条件 | 退出条件 | 行为 |
|------|---------|---------|------|
| **MapIdle** | 大地图打开，标记静止 | 玩家开始移动 / 点击地点 / 退回 | 显示地图，标记在当前地点，等待操作 |
| **MapMoving** | 玩家操作标记移动 | 标记到达地点 / 触发奇遇 / 玩家停止 | 标记沿路径移动，累计距离，推进游戏时间 |
| **MapEncounter** | 标记经过隐藏触发点 | 奇遇事件结束 | 暂停移动和时间累计，播放奇遇事件（对话/战斗/描述） |
| **MapEntering** | 标记到达可进入地点 | 场景加载完毕 | 播放进入过渡动画，加载目标地点入口场景 |
| **MapBlocked** | 标记靠近锁定区域 | 独白播放完毕 | 触发主角内心独白（角色化拒绝），标记不进入该区域 |

#### 区域访问状态

每个地点的访问状态转换：

```
locked → known → unlocked
```

- `locked → known`：主线事件 / NPC 提及 / 书信中出现 → 发送 `location_revealed(id)`
- `known → unlocked`：主线条件满足 / 特定支线完成 → 发送 `location_unlocked(id)`
- 状态变化不可逆 — 解锁后永远可前往（除非剧情临时封锁，用单独标记处理）

### Interactions with Other Systems

| 系统 | 方向 | 接口描述 |
|------|------|---------|
| **主线叙事** | 叙事 → 场景 | `location_revealed(id)` / `location_unlocked(id)` 事件驱动地点可见性；`force_weather(type, duration)` 剧情强制天气 |
| **自然日系统** | 双向 | 场景管理推进时间（大地图旅行/驿站）；日历推进触发 `season_changed` / `day_advanced` / `shichen_changed`，场景管理据此更新季节/天气/时辰状态 |
| **体力系统** | 双向 | 大地图移动消耗体力（`consume_stamina(amount)`）；查询当前体力（`get_stamina()`）决定速度修正；体力为 0 时降速 50% |
| **心境双轴** | 心境 → 场景 | 终幕章节色调根据心境坐标选取；场景管理查询 `get_mindset_zone()` 决定终幕色调方案 |
| **对话系统** | 场景 → 对话 | 大地图锁定区域的角色化拒绝复用 InnerMonologue 格式；场景内 NPC 位置信息供对话条件查询 |
| **NPC 状态管理** | 双向 | 进入场景时查询当前场景应出现哪些 NPC；NPC 状态变化可能解锁新连接（如"密道发现"） |
| **经济系统** | 场景 → 经济 | 驿站使用时扣除费用（`spend_money(amount)`）；查询玩家余额判断是否可使用驿站 |
| **存档系统** | 双向 | 持久化：当前地点+场景+位置、所有地点访问状态、当前季节/天气/时辰、大地图标记位置、驿站解锁状态 |
| **活江湖层** | 活江湖 → 场景 | 活江湖事件可能动态添加大地图奇遇点；传闻系统可触发 `location_revealed` |
| **探索/洞察** | 场景 → 探索 | 场景内洞察触发点的位置管理；大地图奇遇中部分为洞察型发现 |

接口所有权：场景管理系统定义并维护空间状态（地点/场景/季节/天气），其他系统通过查询接口读取，通过事件接口写入。

## Formulas

### 1. 时辰系统

```
一个游戏日 = 12 时辰
```

| 序号 | 时辰 | 现实对应 | 光照分类 |
|------|------|---------|---------|
| 1 | 子时 | 23:00-01:00 | 夜 |
| 2 | 丑时 | 01:00-03:00 | 夜 |
| 3 | 寅时 | 03:00-05:00 | 晨 |
| 4 | 卯时 | 05:00-07:00 | 晨 |
| 5 | 辰时 | 07:00-09:00 | 日 |
| 6 | 巳时 | 09:00-11:00 | 日 |
| 7 | 午时 | 11:00-13:00 | 日 |
| 8 | 未时 | 13:00-15:00 | 日 |
| 9 | 申时 | 15:00-17:00 | 日 |
| 10 | 酉时 | 17:00-19:00 | 昏 |
| 11 | 戌时 | 19:00-21:00 | 昏 |
| 12 | 亥时 | 21:00-23:00 | 夜 |

- 光照分类：日（5 时辰）、晨（2 时辰）、昏（2 时辰）、夜（3 时辰）
- 时辰切换时发送 `shichen_changed(new_shichen)` 事件
- 光照分类切换时发送 `light_category_changed(new_category)` 事件
- 场景加载对应光照变体；背景人物、商铺开关、NPC 出没可绑定时辰或光照分类条件

### 2. 大地图旅行（时间 + 体力）

```
每移动 1 格：
  时间消耗 = 0.01 游戏日（≈ 0.12 时辰）
  体力消耗 = 0.2 点
```

- `time_per_unit` 默认 = 0.01 天/格（Tuning Knobs 可调）
- `stamina_per_unit` 默认 = 0.2 点/格（Tuning Knobs 可调）
- 实时扣除：每格移动后立即推进时间和扣减体力
- 移动可能跨越时辰/日/季节边界，逐格检查并触发对应事件
- 奇遇触发期间暂停时间和体力消耗

速度修正：
```
实际移动速度 = 基础速度 × 速度系数
速度系数 = 体力 > 0 ? 1.0 : 0.5
```
- 体力 = 0 时移动速度降低 50%（等效每格消耗 0.02 天），不再扣除体力
- 体力不会降为负数

### 3. 驿站快速旅行

```
驿站旅行时间 = 步行时间 × 0.5 = 距离(格) × 0.01 × 0.5
驿站体力消耗 = 0
驿站费用 = base_fee + distance_fee × 距离(格)
```

- 到达后一次性推进时间（传送中不逐格触发事件）
- 传送过程中不触发大地图奇遇

### 4. 天气日刷新概率

```
最终概率池 = 季节基础权重表[当前季节] × 区域过滤掩码[当前区域]
随机抽取天气 = weighted_random(最终概率池)
天气持续天数 = random(1, 3)
```

- 季节基础权重表示例（冬）：晴 20%、多云 15%、小雨 0%、大雨 0%、雪 40%、雾 15%、风沙 10%
- 区域过滤掩码：`1 = 允许 / 0 = 禁止`（如江南禁止风沙，塞北禁止小雨/大雨）
- 过滤后重新归一化为 100%
- 剧情强制天气覆盖一切：`if is_forced → 天气 = forced_type，持续到事件结束`

### 5. 章节色调叠加

```
最终色调 = 章节基础调色板 + 季节偏移量[季节][灵敏度等级] + 光照偏移[光照分类]
```

分量计算：
- 色相：`H_final = H_chapter + H_season_offset`
- 饱和度：`S_final = clamp(S_chapter + S_season_offset + S_light_offset, 0, 1)`
- 明度：`V_final = clamp(V_chapter + V_season_offset + V_light_offset, 0, 1)`

季节偏移量由 `season_sensitivity` 等级决定：

| 灵敏度 | H偏移范围 | S偏移范围 | V偏移范围 |
|--------|----------|----------|----------|
| none | 0 | 0 | 0 |
| low | ±5° | ±0.03 | ±0.02 |
| medium | ±15° | ±0.08 | ±0.05 |
| high | ±30° | ±0.15 | ±0.10 |

光照分类偏移：

| 光照分类 | S偏移 | V偏移 |
|---------|-------|-------|
| 日 | 0 | 0 |
| 晨 | -0.03 | -0.08 |
| 昏 | -0.03 | -0.12 |
| 夜 | -0.05 | -0.15 ~ -0.25（按场景 `night_darken` 参数） |

### 6. 奇遇触发判定

```
可触发 = 所有前置条件满足(季节、天气、时辰、主线进度、心境区间)
实际触发 = 可触发 AND random() < trigger_chance
```

- 同一触发点多个奇遇时，按优先级排序，取第一个满足条件的
- 同一奇遇触发后是否可重复，由配置字段 `repeatable` 控制
- 不可重复奇遇触发后标记为 `consumed`，不再参与判定

## Edge Cases

**1. 旅行中跨越多重时间边界**
- 玩家可在大地图自由走动（含往返闲逛），长时间移动可能跨越多个时辰、多日、甚至多个季节
- 处理顺序：每格移动后逐一检查 → 先判时辰切换 → 再判日切换（触发天气刷新）→ 再判季节切换
- 多次跨越时逐个触发对应事件，不跳过中间状态

**2. 奇遇触发与时辰边界同时发生**
- 优先级：先暂停时间 → 触发奇遇 → 奇遇结束后再应用时辰切换

**3. 剧情强制天气与日刷新冲突**
- 剧情强制天气期间，日刷新跳过 — 强制天气优先
- 强制天气结束后，下次日切换时正常刷新

**4. 剧情强制切场与玩家正在大地图移动**
- 立即中断移动，已移动距离的时间和体力正常扣除，然后执行强制切场

**5. 体力为 0 时触发战斗奇遇**
- 正常进入战斗（战斗减益由战斗系统处理），战斗结束后恢复大地图移动（仍为半速）

**6. 驿站费用不足**
- 目的地选项显示费用，不足时置灰并显示角色化提示（如"囊中羞涩，还是走着去吧。"）

**7. 存档/读档与状态恢复**
- 大地图移动中存档：保存标记当前坐标 + 当前时辰 + 当前体力
- 读档后从标记位置继续，不重复扣除时间和体力

**8. 场景加载失败**
- 预加载目标场景失败：保持全黑/全墨状态，重试 3 次
- 3 次均失败：回退到上一个场景，弹出存档建议（非崩溃处理）

**9. 锁定区域无独白文本**
- 配置遗漏时的兜底：使用通用独白"此处……不急于一时。"
- 开发阶段标记为警告日志，确保上线前补全

**10. 季节/光照切换的视觉突变**
- 季节切换时用 2 秒线性过渡混合新旧色调偏移
- 光照分类切换（晨→日、日→昏、昏→夜）同样用 2 秒过渡

**11. 新场景加载时的光照/天气状态**
- 进入新场景时必须立即应用当前时辰的光照变体 + 当前天气效果
- 不能先加载默认状态再切换（避免闪烁）
- 预加载阶段即传入当前光照/天气参数

**12. 驿站传送跨越日/季节边界**
- 驿站传送本身有黑屏→白屏过渡动画，直接展示落地后的时间和季节状态
- 到达后一次性应用所有跨越的状态变化（天气刷新、季节切换等），无需额外视觉过渡

**13. 限时主线任务超时**
- 部分主线任务有时间限制（以游戏日计），若玩家在大地图闲逛导致超时
- 处理：超时时通过事件或对话强制将玩家带入后续剧情（如NPC赶来通知、突发事件打断行程）
- 强制推进视为剧情强制切场，按第4条处理

## UI Requirements

**1. 大地图界面**

- 全屏展示，水墨风格地图底图
- 显示元素：
  - 主角标记（可操控移动）
  - 地点图标 + 名称标签（按 access_state 显示：locked 不显示 / known 灰色 / unlocked 正常）
  - 驿站图标（已解锁显示为可交互，未解锁不显示）
- 界面信息栏（角落）：
  - 当前时辰（如"午时"）
  - 当前天气图标
  - 当前季节（如"秋"）
  - 体力条（简化显示）
  - 银两数（驿站使用时参考）
- 操作：
  - 点击/按住方向移动标记
  - 点击驿站图标打开驿站面板
  - 点击已解锁地点图标可选择"进入"
  - 按钮：返回当前场景

**2. 驿站面板**

- 弹出式面板，列出所有已解锁驿站
- 每个驿站选项显示：
  - 地点名称
  - 距离（格数）
  - 预计时间消耗
  - 费用
- 余额不足的选项置灰，附角色化提示
- 确认按钮 + 取消按钮

**3. 场景内地图（只读）**

- 半透明叠加层或侧边栏
- 显示大地图简化版：当前位置高亮 + 已知地点分布
- 不可交互，仅供查看
- 关闭按钮 / 再次按地图键关闭

**4. 过渡画面**

- 淡入淡出：全黑遮罩，透明度 0→1→0
- 水墨晕染：从屏幕边缘向中心晕开的墨色覆盖，再从中心向边缘散开
- 加载中无额外提示（用户感知为过渡动画的一部分）

**5. 锁定区域独白**

- 复用对话系统的 InnerMonologue 显示样式
- 位置：屏幕下方居中，半透明底条 + 主角内心独白文字
- 自动消失（约 2-3 秒）或玩家点击消失

**6. 时辰/天气/季节切换提示**

- 不做弹窗打断
- 时辰切换：屏幕角落小字浮现后淡出（如"—— 酉时 ——"）
- 季节切换：屏幕中央水墨文字浮现（如"—— 秋 ——"），约 1.5 秒后淡出
- 天气变化：无文字提示，仅靠粒子效果和音效传达

## Acceptance Criteria

**场景加载与切换：**
1. 玩家触发出口后，过渡动画 + 场景加载 + 进入新场景全程无卡顿（预加载命中时）
2. 预加载未完成时，全黑/全墨等待期间帧率不掉
3. 场景切换后玩家位置正确放置在目标入口点

**区域解锁与访问控制：**
4. locked 状态地点在大地图上完全不可见
5. known 状态地点可见但不可交互，标记无法进入
6. unlocked 状态地点可正常进入
7. 接收到 `location_revealed` / `location_unlocked` 后状态立即生效

**时辰系统：**
8. 12 时辰按游戏日正确循环，每个时辰持续 1/12 游戏日
9. 时辰切换时光照变体正确过渡（2 秒内），无突变闪烁
10. 进入新场景时立即应用当前时辰的光照状态

**季节与天气：**
11. 季节按 30 天/季正确循环
12. 天气每日刷新符合概率池规则（区域过滤正确、归一化正确）
13. 剧情强制天气期间不被日刷新覆盖
14. 不同 `season_sensitivity` 等级的场景视觉差异符合设计（none 无变化、high 明显变化）

**大地图旅行：**
15. 每格移动实时消耗 0.01 天和 0.2 体力
16. 体力为 0 时移动速度明显降低（50%），不再扣除体力
17. 大地图自由移动无隐形边界（除地图四边和海岸线）
18. 奇遇触发时正确暂停时间和体力消耗

**驿站：**
19. 仅在大城市/大门派附近存在驿站
20. 首次步行到达驿站后解锁，之后可双向传送
21. 费用正确扣除，余额不足时选项置灰且显示角色化提示
22. 传送时间 = 步行时间 × 0.5，不触发奇遇

**色调系统：**
23. 章节色调 + 季节偏移 + 光照偏移三层正确叠加
24. 终幕色调根据心境双轴输出正确选取 5 种方案之一

**角色化拒绝：**
25. 标记靠近锁定区域时触发内心独白，非系统弹窗
26. 独白文本根据当前主线状态选取，无配置遗漏（兜底文本生效）

**边界情况：**
27. 长时间移动跨越多日/季节时所有事件按序触发，不跳过
28. 限时主线超时后强制推进正确执行
29. 存档/读档后所有状态（坐标、时辰、体力、天气、季节）正确恢复
