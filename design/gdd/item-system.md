# 物品 / 道具 (Item System)

> **Status**: Designed
> **System #**: 15
> **Category**: Economy
> **Priority**: Vertical Slice
> **Depends On**: 角色属性(硬), 武学组合(软)
> **Referenced By**: 自然日+体力, 行气战棋战斗, 武学组合, 朦胧化 UI

---

## A. Overview

### 定位

物品/道具系统是《风止》的**资源管理与轻量经济层**——管理玩家在江湖旅途中获取、携带、使用和交换的一切有形物件。它不追求复杂的通货膨胀或稀缺度模拟，而是服务于三个核心体验：

1. **战斗准备的策略深度** — 战前选择携带哪些消耗品，战中决定是否用一次自然行动出手动作使用道具（机会成本 = 放弃出招、调息、切换内功或轻功）
2. **探索的奖励感** — 残卷、秘籍、信物等关键物品作为探索和叙事的物质化反馈
3. **江湖生存的节奏感** — 食物恢复体力形成"客栈 vs 干粮"的路线规划抉择

### 设计哲学

参考**逸剑风云决**的草药采集/炼丹/锻造深度和**金庸群侠传**的经典装备/秘籍收集体验，但做减法：

- **战斗不卖药** — 道具使用占用行气满后的出手动作，是"放弃进攻或调息的代价"而非"无脑续命"；不设次数上限，行动机会本身即平衡机制
- **无限背包，有限堆叠** — 不制造整理焦虑，但堆叠上限迫使玩家消费而非囤积
- **品级定底子，词条看造化** — 装备品级（九品→一品→传说）固定于物品定义；品级决定基础属性和词条数量上限，词条数值随机体现"同一把剑也有优劣"的锻造感，但装备不设颜色品质标签（丹药品质保留色标以区分极/上/中/下四档）
- **银两轻经济 + 江湖拍卖** — 基础买卖走客栈/NPC 商店；稀有物品走黑市/江湖拍卖（以物易物 + 银两竞拍），不做通货膨胀或稀缺度曲线
- **关键物品不可丢弃** — 残卷、书信、信物等叙事道具永久保留，防止卡关
- **武学可传授** — 残卷/秘籍获得后可选择自学或教授同伴，形成队伍构建的资源分配抉择

### 物品分类

| 类别 | 子类 | 战斗中可用 | 可堆叠 | 可交易 |
|------|------|-----------|--------|--------|
| **消耗品：战斗** | 伤药、解毒散、内息丹、强化符 | ✅（占用出手动作） | ✅ | ✅ |
| **消耗品：探索** | 干粮、酒水、茶叶、香料 | ❌ | ✅ | ✅ |
| **装备** | 武器、护甲、饰品 | ❌（战前装配） | ❌ | ✅ |
| **关键物品** | 残卷、秘籍、书信、信物、任务道具 | ❌ | ❌ | ❌（部分可拍卖） |

### 与行气战棋战斗的集成

道具使用嵌入行气驱动的自然行动结构：

- **时机**：角色行气满并完成移动选择后，可选择"使用道具"作为本次出手动作。
- **代价**：消耗本次自然行动的出手机会 — 不能同时出招、调息、切换内功或使用轻功。
- **无次数限制**：行动机会本身即平衡杠杆；每次用药都会推迟输出、取位或调息节奏。
- **战术定位**：道具是"续命但失去压迫节奏"的保守选择，与行气、破绽和决胜窗口形成张力。

### 经济模型

- **货币**：银两（唯一通货）
- **产出**：战斗奖励、探索拾取、任务奖励、分解多余残卷
- **消耗**：商店购买、客栈住宿（高级客栈）、锻造/炼药材料费、拍卖竞价
- **拍卖渠道**：黑市（固定NPC，以物易物为主）、江湖拍卖会（事件驱动，银两竞拍，稀有装备/秘籍流通）
- **平衡原则**：玩家应常态"小富"但无法暴富，迫使在"买药 vs 升级装备 vs 攒钱竞拍"间取舍

## B. Player Fantasy

### 核心幻想

> "打开包袱，翻出一粒金创药递给她，又摸出半壶竹叶青放在桌上。"

玩家扮演的不是 RPG 商人，而是**行走江湖的侠客** — 包袱里装的是救命的伤药、师门传下的残卷、路上偶得的奇兵。每一件物品都有来历，每一次使用都有取舍。

### 情感锚点

1. **"翻包袱"的温暖感** — 打开背包时看到一路收集的物件，回忆起每件东西的来历（书信来自谁、这把剑在哪得到的）
2. **"教徒弟"的成就感** — 把自己已经学会的招式秘籍传授给同伴，看着队伍整体变强
3. **"摆摊/竞拍"的江湖感** — 黑市淘宝、拍卖会上与其他江湖人争抢稀世秘籍的紧张刺激
4. **"最后一颗药"的抉择感** — 战斗中手握最后一瓶伤药，用还是不用？用了这次自然行动就不能出招或调息

### 参考体验

- **金庸群侠传**：收集各派秘籍的满足感，装备系统的朴素直接
- **逸剑风云决**：草药采集→炼丹→使用的完整链条，锻造系统的深度
- **仙剑奇侠传**：道具在战斗中的策略性使用（占用行动机会），关键物品推动剧情
- **大侠立志传**：自由度极高的物品获取路径、以物易物的江湖交易氛围、道具驱动的多结局分支

## C. Detailed Design

### Core Rules

#### CR-1. 背包管理（无限容量 + 堆叠上限）

- 背包无槽位限制，物品按类别自动分组
- 每种可堆叠物品有独立的 `max_stack`（默认 99，特殊道具可配置）
- 达到堆叠上限时自动溢出为新堆叠（不拒绝获取）
- 排序规则：关键物品 > 装备（按品级降序）> 消耗品：战斗 > 消耗品：探索；同类内按获取时间逆序

#### CR-2. 装备系统（5 槽 + 品级/品质/词条）

每个可玩角色都有一套独立装备槽。主角与同伴槽位完全相同，装备库由队伍共享，但同一件装备实例同一时间只能被一个角色穿戴。

**槽位定义**：

| 槽位 | 类型 | 主要影响属性 |
|------|------|-------------|
| 主手 | 武器 | 攻击、暴击、行气词条（仅显式词条生效） |
| 身甲 | 护甲 | 防御、气血上限 |
| 足具 | 鞋 | 移动、闪避、行气词条（仅显式词条生效） |
| 饰品 1 | 饰品 | 任意属性（由具体饰品定义） |
| 饰品 2 | 饰品 | 任意属性（由具体饰品定义） |

**角色装备规则**：

- 主角和同伴均拥有上述 5 个装备槽。
- 背包/装备库归队伍共享，不按角色拆分库存。
- 装备实例具有唯一 `item_instance_id`，装备后绑定 `equipped_by_character_id`。
- 同一装备实例不能同时装备给多个角色；若要转移，必须先从原角色卸下。
- 特定剧情可临时锁定某角色装备槽（如伪装、受伤、缴械），但这是内容特例，不是同伴默认限制。

**品级体系（Grade）**：

| 品级 | 基础属性系数 | 稀有度 | 获取途径 |
|------|-------------|--------|----------|
| 九品 | ×1.0 | 极常见 | 初始/商店 |
| 八品 | ×1.2 | 常见 | 商店/低级掉落 |
| 七品 | ×1.5 | 普通 | 掉落/锻造 |
| 六品 | ×1.8 | 较少 | 中级掉落/锻造 |
| 五品 | ×2.2 | 稀有 | 高级掉落/锻造 |
| 四品 | ×2.7 | 稀有 | Boss/拍卖 |
| 三品 | ×3.3 | 珍贵 | Boss/拍卖/任务 |
| 二品 | ×4.0 | 极珍贵 | 主线/隐藏任务 |
| 一品 | ×5.0 | 极稀有 | 终章/隐藏 Boss |
| 传说 | ×7.0 | 全游戏个位数 | 唯一获取条件 |

- 品级固定于物品定义（同名装备品级永远相同）
- 品级决定基础属性（固定值，无随机）：`base_attr = template_attr × grade_multiplier`
- 品级越高 → 基础属性越高，这是装备的"底子"

**词条体系（Affixes）**：

- 装备生成时从该品级的词条池中随机抽取词条
- 词条数由品级固定决定（非随机）：

| 品级范围 | 词条数 |
|---------|--------|
| 九品–七品 | 1 |
| 六品–四品 | 2 |
| 三品–二品 | 3 |
| 一品 | 4 |
| 传说 | 固定（手工设计，见下方说明） |

- 词条数值随机范围 = 满值的 **40%–100%**（下限保底，不会出现废词条）
- **不设品质颜色标签** — 词条好坏通过朦胧化 UI 的文学描述表达（如"此剑锋锐异常"vs"此剑尚算趁手"），不显示百分比或颜色
- **重复获取刷新**：1-9品装备可在游戏中重复获取（同品级同名装备再次掉落时生成新词条），玩家通过重复获取逐步优化装备，无需独立的"洗词条"系统

**传说装备（唯一物品）**：

- 全游戏仅此一件，不可重复获取
- 属性和词条全部由设计师手工固定（无随机）
- 每件传说装备附带叙事背景（来历、故事），作为探索和叙事的物质化锚点

**装备系统 Anti-Pillar 约束（W16）：**

为防止装备词条系统诱导"数值刷怪"行为（Anti-Pillar: NOT 高频战斗/数值刷怪），设定以下硬约束：

| 约束 | 规则 | 理由 |
|------|------|------|
| **装备总贡献上限** | 全身装备属性总和 ≤ 基础属性（无装备时）× `equip_contribution_cap`（默认 0.40） | 装备是锦上添花而非决定性因素 |
| **无套装效应** | 不设计套装系统或多装备协同加成 | 杜绝"凑套装"导致的刷怪动机 |
| **品级章节门控** | 高品装备只在对应章节后的商店/掉落中出现（四品以上 = 第三章+） | 无法通过反复刷早期内容获取高品 |
| **词条类型简化** | 词条池仅含 4 大类（攻击系/防御系/内息系/洞察系），无交叉增益词条 | 不鼓励计算"最优词条组合" |
| **掉落确定性** | 每个敌人的掉落物固定（品级固定、词条随机但数值区间窄 40%-100%），非概率掉落 | 消除"刷掉落"动机 |
| **精炼次数限制** | 每件装备精炼上限 3 次（非无限强化） | 防止沉迷强化循环 |

> **设计哲学**：装备在本项目中的定位是"叙事锚点 + 轻度个性化"，而非"战力核心"。玩家获得新装备应因为"这把剑有故事"而非"这把剑 DPS 高 3%"。朦胧化 UI 不显示精确数值进一步削弱了 min-max 动机。

#### CR-3. 战斗道具使用

- 战斗中，角色行气满进入行动选择后，可选择：**"使用道具"**（combat-system 出手动作之一）
- 选择后打开战斗背包界面（仅显示 `combat_usable: true` 的物品）
- 使用道具 = 消耗本次自然行动的出手动作 → 本次行动不可同时出招、调息、切换内功或使用轻功
- 道具效果立即生效（治疗立即加血、增益立即上 buff）
- 无单场使用次数上限 — 代价是自然行动机会本身
- 若当前持有 0 个可用战斗道具，"使用道具"按钮置灰

#### CR-4. 制作系统（炼丹 + 锻造）

**炼丹（草药 → 丹药/伤药）**：
- 需要"药炉"交互点（客栈、据点中的固定设施）
- 配方 = 草药组合 → 产出丹药
- 配方需通过探索/购买/任务获得（关键物品类型）
- 炼丹产出品质：极/上/中/下，分别发挥面板药效的 **120% / 100% / 80% / 60%**
- 品质由配方等级、草药品级（草药本身无品质但有品级之分）和角色熟练度决定
- 基础材料（草药/矿物）：无品质浮动，仅有品级区分

**锻造（矿石/材料 → 装备）**：
- 需要"铁匠铺"交互点（特定场景中的固定设施）
- 配方 = 材料组合 + 银两 → 产出装备
- 锻造产出的装备品级由配方决定（固定），品质/词条在生成时随机
- 可对现有装备进行"精炼"（消耗材料提升基础属性，向上限逼近）
- 精炼上限：每项属性最多精炼至该品级上限的 95%

#### CR-5. 经济规则

- 银两为 `uint` 类型，不可为负
- NPC 商店售价固定（配置表驱动），买入价 = 售价 × `sell_ratio`（默认 0.3）
- 黑市：固定 NPC，以物易物为主（指定"交换条件" = 特定物品组合）
- 江湖拍卖会：由活江湖层事件触发，竞拍起价 + 加价步进，NPC 竞价 AI 简单递增
- 分解：多余残卷/装备可分解为基础材料 + 少量银两

#### CR-6. 关键物品与传授

- 关键物品获取后进入独立列表（不与消耗品/装备混排）
- 不可丢弃、不可出售（部分标记 `auctionable: true` 的可参与拍卖）
- **残卷/秘籍传授**：
  - 若该武学主角已学会 → 可选择"传授"给任意同伴
  - 传授后残卷消耗，同伴获得该招式（调用 `OnFragmentObtained(moveId, target_character)`）
  - 若主角未学会 → 只能自学，不可传授

### States

物品生命周期状态：

```
[未获得] → OWNED → EQUIPPED (仅装备类)
                 → CONSUMED (消耗品使用后)
                 → TAUGHT (残卷传授后)
                 → SOLD (出售/拍卖后)
                 → DECOMPOSED (分解后)
```

- `OWNED`：在背包中，可操作
- `EQUIPPED`：装备中，modifiers 生效
- `CONSUMED / TAUGHT / SOLD / DECOMPOSED`：从背包移除（存档中仅保留 log）

### Interactions (接口清单)

| 方向 | 系统 | 接口 | 描述 |
|------|------|------|------|
| → | 角色属性 | `ApplyModifiers(character_id, mods[])` | 装备写入修改器 |
| → | 角色属性 | `RemoveModifiers(character_id, equip_id)` | 卸装时移除修改器 |
| → | 队伍管理 / 同伴成长 | `EquipItem(character_id, item_instance_id, slot_id)` | 为指定可玩角色穿戴装备 |
| → | 队伍管理 / 同伴成长 | `GetEquippedBy(item_instance_id)` | 查询装备实例当前归属，防止多人共用 |
| → | 武学组合 | `OnFragmentObtained(moveId, target)` | 残卷使用/传授 |
| → | 自然日+体力 | `restore_stamina(amount)` | 食物道具恢复体力 |
| → | 行气战棋战斗 | `RegisterCombatAction("use_item")` | 注册行气行动中的出手动作 |
| ← | 行气战棋战斗 | `OnBattleReward(loot_table_id)` | 战斗掉落 |
| ← | 主线叙事 | `GrantItem(item_id, qty, quality_override?)` | 剧情奖励（可指定品质） |
| ← | 探索/洞察 | `GrantItem(item_id, qty)` | 探索拾取 |
| ← | 活江湖层 | `TriggerAuction(auction_config)` | 触发拍卖会 |
| ↔ | 存档系统 | `SerializeInventory()` / `LoadInventory()` | 持久化 |

## D. Formulas & Data

### F1. 装备基础属性

品级决定基础属性，无随机：

```
base_attr = template_attr × grade_multiplier
```

`grade_multiplier` 见 CR-2 品级表（×1.0 至 ×7.0）。

### F2. 词条生成

**词条生成**：

```
affix_count = GRADE_AFFIX_COUNT[grade]
// {九品:1, 八品:1, 七品:1, 六品:2, 五品:2, 四品:2, 三品:3, 二品:3, 一品:4}
// 传说装备词条由设计师手工定义，不走此生成逻辑
for each affix:
    affix.value = random_int(affix.max × 0.4, affix.max)  // 下限40%保底
```

**重复获取**：

```
// 玩家再次获得同名同品级装备时：
new_equipment = generate_with_new_affixes(template, grade)
// 玩家可选择保留旧装备或替换为新装备
```

> **注意**：不再计算品质评分或颜色标签。词条好坏由朦胧化 UI 的文学描述表达。

### F3. 丹药品质与药效

丹药品质独立于装备品质体系，直接影响药效系数：

| 丹药品质 | 药效系数 | 颜色 |
|---------|---------|------|
| 极品 | ×1.2（面板药效的 120%） | 金色 |
| 上品 | ×1.0（面板药效的 100%） | 紫色 |
| 中品 | ×0.8（面板药效的 80%） | 蓝色 |
| 下品 | ×0.6（面板药效的 60%） | 绿色 |

丹药品质由炼丹条件决定（草药稀有度 + 配方等级 + 角色熟练度），具体公式待 tuning。

### F4. 精炼公式

```
delta = base_refine_amount × (material_grade / 5)
new_attr = min(current_attr + delta, grade_cap × 0.95)
```

每项属性精炼上限 = 品级上限 × 95%。

### F5. 经济价值

```
sell_price = base_price × sell_ratio  // sell_ratio 默认 0.3
decompose_yield = floor(base_price × 0.15) (银两) + 材料碎片
```

### F6. 稀有度标识

基础材料和丹药使用稀有度标识珍贵程度（与装备品级类似但独立）：

| 稀有度 | 含义 | 示例 |
|--------|------|------|
| 凡品 | 随处可得 | 普通草药、铁矿 |
| 良品 | 需特定区域采集 | 灵芝、精铁 |
| 珍品 | 稀有产地/事件限定 | 雪莲、寒铁 |
| 绝品 | 极难获取，全游戏限量 | 千年何首乌、陨铁 |

## E. Edge Cases

1. **背包满堆叠时获取新物品**：自动创建新堆叠，永远不拒绝拾取。
2. **战斗中最后一件消耗品用完**：立即隐藏或置灰"使用道具"选项（战斗中动态更新可用性）。
3. **装备被另一角色穿着时尝试转移**：提示"需先卸下"，禁止直接转移。
4. **同一饰品装备到两个槽位**：禁止。同一件实例只能占一个槽。
5. **传说装备分解**：弹出二次确认"此装备全游戏仅此一件，确认分解？"。
6. **拍卖中银两不足**：出价时即时校验余额，不足则禁止出价。
7. **NPC 竞价超过玩家当前银两**：玩家可选择放弃或加价（如有足够银两）。
8. **炼丹/锻造材料不足**：按钮置灰 + 显示缺少的材料及数量。
9. **关键物品标记 auctionable 但拍卖失败（无人出价）**：物品返回背包。
10. **精炼已达上限的属性**：该属性精炼按钮置灰，提示"已达精炼上限"。
11. **传授武学给已学会该招式的同伴**：禁止传授，提示"对方已习得此招"。
12. **战斗中角色死亡后行气进入行动队列**：从行动队列移除（死亡角色不能使用道具复活自己）。

## H. Acceptance Criteria

1. **GIVEN** 玩家击败敌人，**WHEN** 战斗结束，**THEN** 根据 loot_table 生成物品并加入背包。
2. **GIVEN** 玩家拥有战斗消耗品，**WHEN** 角色行气满并进入出手动作选择，**THEN** "使用道具"选项可用；选择后消耗本次出手动作、物品生效。
3. **GIVEN** 玩家装备一把五品武器，**WHEN** 查看角色属性面板，**THEN** 攻击力增加 `template_attack × 2.2`。
4. **GIVEN** 装备为六品（2条词条），**WHEN** 查看装备信息，**THEN** 通过朦胧化 UI 文学描述表达词条效果，不显示颜色标签或百分比。
5. **GIVEN** 玩家在药炉炼制丹药，**WHEN** 炼制完成，**THEN** 丹药品质为极/上/中/下之一，药效为面板值的 120%/100%/80%/60%。
6. **GIVEN** 玩家已学会某招式且持有对应残卷，**WHEN** 选择"传授"并指定同伴，**THEN** 残卷消耗、同伴获得该招式。
7. **GIVEN** 拍卖会进行中，**WHEN** 玩家出价高于当前最高且 NPC 未跟价，**THEN** 玩家获得拍品、银两扣除。
8. **GIVEN** 装备精炼至 95% cap，**WHEN** 尝试继续精炼该属性，**THEN** 按钮置灰、显示"已达上限"。
9. **GIVEN** 基础材料"雪莲"稀有度为"珍品"，**WHEN** 查看物品信息，**THEN** 显示稀有度标签但无品质颜色。
10. **GIVEN** 玩家银两不足以出价，**WHEN** 在拍卖会尝试出价，**THEN** 出价按钮置灰。
11. **GIVEN** 同伴打开装备界面，**WHEN** 查看槽位，**THEN** 显示与主角一致的主手、身甲、足具、饰品 1、饰品 2。
12. **GIVEN** 一件装备已由主角穿戴，**WHEN** 玩家尝试直接给同伴装备同一实例，**THEN** 系统提示需先卸下，且不会产生双重装备。
