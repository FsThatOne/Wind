# 设置/选项 (Settings & Options)

> **Status**: Designed
> **Author**: user + agents
> **Last Updated**: 2026-06-08
> **Implements Pillar**: —（基础设施系统，不直接实现设计支柱）

## Overview

设置/选项系统是《风止》的玩家偏好配置中心，同时承载游戏暂停菜单和退出功能。它管理三类配置：**音频**（Master/BGM/Ambient/SFX 四档音量）、**显示**（分辨率、窗口模式、字体缩放）、**游戏**（对话文字速度）。所有配置独立存储于 `user://settings.cfg`（不加密，与存档分离），启动时自动加载。

系统遵循两条原则：
1. **实时预览**：所有设置修改立即生效，无需"应用"按钮（分辨率例外，需确认）
2. **极简选项**：不提供难度设置（游戏通过机制设计自调节），不暴露内部 Tuning Knobs

## Player Fantasy

"设置不该成为一种体验——它应该在 5 秒内解决问题，然后消失。"

设置系统的情感目标是**透明感**——玩家调完音量、改完分辨率，回到游戏时几乎不记得自己离开过。与教学系统类似，它的成功标准是"感受不到它的存在"。

## Detailed Design

### Core Rules

**R1. 设置分类与选项列表**

| 类别 | 选项 | 类型 | 默认值 | 范围 |
|------|------|------|--------|------|
| 音频 | Master 音量 | int slider | 80 | 0–100 |
| 音频 | BGM 音量 | int slider | 80 | 0–100 |
| 音频 | 环境音音量 | int slider | 80 | 0–100 |
| 音频 | SFX 音量 | int slider | 80 | 0–100 |
| 显示 | 分辨率 | dropdown | 当前屏幕分辨率 | 系统支持的分辨率列表 |
| 显示 | 窗口模式 | dropdown | 全屏 | 全屏 / 窗口化 / 无边框窗口 |
| 显示 | 字体缩放 | dropdown | 100% | 80% / 100% / 120% / 150% |
| 游戏 | 文字显示速度 | dropdown | 标准 | 慢(15) / 标准(30) / 快(60) / 瞬间(∞) chars/sec |

**R2. 暂停菜单**

- 游戏中按 `Esc` / 手柄 `Start` 打开暂停菜单
- 暂停时 `Engine.TimeScale = 0`，所有游戏逻辑冻结
- **一击决胜演出期间不可暂停**——按 Esc 无效，演出结束后才响应

**非战斗状态**菜单项：

1. 继续游戏
2. 存档
3. 读档
4. 设置（打开设置子面板）
5. 返回标题画面（弹出未保存确认框）
6. 退出游戏（弹出未保存确认框）

**战斗状态**菜单项（隐藏存档）：

1. 继续游戏
2. 读档
3. 设置
4. 返回标题画面（弹出未保存确认框）
5. 退出游戏（弹出未保存确认框）

**R3. 持久化规则**

- 设置存储路径：`user://settings.cfg`（Godot ConfigFile 格式）
- 不加密（与存档系统的 AES 加密不同）——配置文件可手动编辑
- 启动时自动加载；如文件缺失或损坏，使用全部默认值
- 设置修改**即时写入**，无需手动保存
- 设置文件与存档槽无关——所有存档共享同一份设置

**R4. 实时预览**

- 音量滑块：拖动时实时调整音频总线增益，松手后写入文件
- 分辨率/窗口模式：选择后立即应用，弹出 10 秒确认倒计时——玩家不确认则自动回退
- 字体缩放：选择后立即应用到所有文字 UI
- 文字速度：下次对话生效

### States and Transitions

```
[Closed] ──Esc/Start──▶ [PauseMenu]
                            │
                     选择"设置" ──▶ [SettingsPanel]
                            │            │
                     选择"继续" ◀── Esc/返回 ◀──┘
                            │
                     选择"存档/读档" ──▶ 委托存档系统 UI
                            │
                     选择"返回标题画面" ──▶ 确认对话框 ──▶ 标题画面场景
                            │
                     选择"退出游戏" ──▶ 确认对话框 ──▶ 退出应用
```

### Interactions with Other Systems

| 系统 | 方向 | 接口 | 说明 |
|------|------|------|------|
| 音频系统 | 设置 → 音频 | `volume_changed(track, value)` | 发射音量变更事件 |
| 音频系统 | 音频 → 设置 | 启动时读取 settings.cfg 音量值 | 初始化音量 |
| 对话系统 | 设置 → 对话 | `DialogueSystem.SetTextSpeed(chars_per_sec)` | 文字显示速度 |
| 存档系统 | 设置 → 存档 | `SaveSystem.SaveGame()` / `LoadGame()` | 暂停菜单中触发存读档 |
| 战斗 UI | 设置 → 战斗UI | `font_scale` 全局变量 | 字体缩放影响所有 UI |
| 战斗系统 | 战斗 → 设置 | `CombatSystem.IsInCinematicLock()` | 一击决胜演出等不可暂停状态查询 |

## Formulas

设置/选项系统不包含数学公式。音量值直接映射为 AudioServer 的线性增益（`value / 100.0`），具体音频衰减公式归属音频系统 GDD。

## Edge Cases

- **如果分辨率切换后确认倒计时内游戏崩溃**：下次启动时 settings.cfg 仍保留旧分辨率（因为新值要确认后才写入）。
- **如果 settings.cfg 被手动修改为非法值**（如音量 = -50）：加载时 clamp 到合法范围，不报错。
- **如果在战斗回合选择阶段按 Esc**：正常打开暂停菜单，战斗逻辑冻结，存档选项隐藏。
- **如果在对话播放中按 Esc**：正常打开暂停菜单，对话文字停止滚动，恢复后继续。
- **如果在一击决胜演出中按 Esc**：无响应，演出结束后 Esc 正常工作。
- **如果玩家在未保存状态下选择"返回标题画面"或"退出游戏"**：弹出确认对话框——"有未保存的进度，确定离开吗？[确定] [取消]"。

## Dependencies

**硬依赖**：无。设置系统可独立运行——即使没有其他系统，设置面板仍可打开和配置。

**软依赖**：

| 依赖系统 | 方向 | 说明 |
|---------|------|------|
| 音频系统 | 双向 | 音量配置。缺失则音量滑块无实际效果 |
| 存档系统 | 单向（设置→存档） | 暂停菜单中的存读档入口。缺失则隐藏对应菜单项 |
| 对话系统 | 单向（设置→对话） | 文字速度。缺失则该设置项不显示 |

**被依赖系统**：音频系统将设置/选项列为硬依赖。

## Tuning Knobs

| 旋钮 | 默认值 | 安全范围 | 说明 |
|------|--------|---------|------|
| `resolution_confirm_timeout_sec` | 10 | 5–30 | 分辨率切换后的确认倒计时秒数 |

仅此一个旋钮。音量默认值（80）和文字速度档位已在 R1 中定义，属于设计常量而非运行时调参。

## Visual/Audio Requirements

无独立美术/音效资源。暂停菜单和设置面板使用通用 UI 样式，不引入专属贴图、动画或音效。

## UI Requirements

| 元素 | 布局 | 交互 |
|------|------|------|
| **暂停菜单** | 居中垂直列表，半透明黑色全屏遮罩（alpha 0.7） | 键盘/手柄上下选择 + 确认；再按 Esc 关闭 |
| **设置面板** | 暂停菜单右侧展开，左侧分类 tab（音频/显示/游戏），右侧选项列表 | 滑块拖拽 / 下拉选择 |
| **分辨率确认对话框** | 居中小窗，显示倒计时 | "确认" / "取消"（倒计时归零自动取消） |
| **退出确认对话框** | 居中小窗 | "确定" / "取消" |

## Acceptance Criteria

| ID | 验收条件 |
|----|---------|
| AC-01 | Esc 键打开暂停菜单，游戏逻辑冻结（TimeScale = 0） |
| AC-02 | 非战斗状态暂停菜单包含 6 项：继续/存档/读档/设置/返回标题画面/退出游戏 |
| AC-03 | 战斗状态暂停菜单隐藏存档选项，包含 5 项 |
| AC-04 | 四档音量滑块拖动时实时改变对应音轨音量 |
| AC-05 | 音量设置修改后退出游戏再启动，值保持不变 |
| AC-06 | 分辨率切换后弹出 10 秒确认倒计时，不确认则自动回退 |
| AC-07 | settings.cfg 缺失时使用默认值启动，不崩溃 |
| AC-08 | settings.cfg 含非法值时 clamp 到合法范围 |
| AC-09 | 文字速度切换后下次对话生效 |
| AC-10 | 一击决胜演出期间 Esc 无响应 |
| AC-11 | 字体缩放修改后所有 UI 文字立即更新 |
| AC-12 | 未保存状态下选择"返回标题画面"或"退出游戏"弹出确认对话框 |

2. **v1.1 多语言**：语言切换选项的 UI 位置和热切换支持方式待定。
3. **键位自定义**：是否支持键盘重映射？手柄是否使用 Godot 内置的 InputMap 暴露给玩家？
