# 顿悟突破 (Epiphany Breakthrough)

> **Status**: Designed
> **Author**: user + agents
> **Last Updated**: 2026-06-06
> **Implements Pillar**: Pillar 2 (每个选择有重量), Pillar 3 (战斗是高手过招)

## Overview

顿悟突破是《风止》的角色成长跃迁系统——让修炼不是线性堆积数值，而是在特定契机下"质变"的瞬间。

它不是一个独立的"迷你游戏"，而是一个**泛场景触发框架**：在战斗的绝境、在叙事的觉醒节点、在呼吸期的静心冥想中，角色可能突然触及更高层次的理解，获得不可逆的永久成长和新能力。

核心职责：
1. **触发判定** — 基于三种场景（战斗绝境 / 叙事脚本 / 呼吸期冥想）的条件检查，判定顿悟机会是否出现
2. **抉择窗口** — 战斗场景中提供"凝神顿悟"vs"稳妥取胜"的风险-收益抉择；非战斗场景为自然进入
3. **顿悟演出与奖励** — 触发专属演出，发放固定属性增长 + 解锁内容（新招式/叙事选项/特殊能力）
4. **境界突破联动** — 当顿悟使功力总值跨越阈值时，触发角色属性系统的境界突破事件
5. **章节门限** — 防止前期过度顿悟破坏成长节奏，每章设置顿悟次数上限

设计哲学：
- **朦胧化原则**：顿悟概率对玩家完全隐藏，玩家感知到的是"绝境中灵光乍现"而非"概率终于触发了"
- **不惩罚放弃**：选择"稳妥取胜"不是错误选择——它给予即时战斗增益，只是放弃了成长机会
- **稀有 = 珍贵**：整个游戏流程中预计 12-18 次顿悟机会，每次都应是令人印象深刻的叙事时刻

## Player Fantasy

**"绝境之中，灵光一闪，我悟了。"**

顿悟突破服务于武侠小说中最经典的"绝境突破"叙事母题——那种在生死一线间突然理解了某个道理、突然打通了某条脉络的高光时刻。

**第一层：绝境生慧**

你被 boss 逼到角落，HP 只剩一线。就在你准备接受失败时，屏幕微微震动，墨色涟漪从角色脚下扩散——系统提示你："你可以凝神顿悟。" 你放弃了安全出招的机会，选择沉入内心。接下来的 3 次自身自然行动窗口里，队友必须替你挡住围攻、牵制敌人、守住那口气。若你撑过这段最危险的空白，闪回画面浮现，你领悟一招新的剑法，战斗以完全不同的节奏继续。

这让玩家感受到：**真正的强大不是一帆风顺地变强，而是在逆境中的觉醒。**

**第二层：放弃也是选择**

同样的绝境时刻，你也可以选择"稳妥取胜"——不冒险凝神，而是获得临时增益（回血回气、清除破绽、下一招必暴击和短时减伤），确保打赢这场仗。你没有顿悟，但你活了下来。下次绝境，机会还会来。

这让"凝神顿悟"成为一个**有意义的风险决策**——不是"你当然要选它"的假选择，而是"我愿不愿意在此刻冒这个险"的真选择。

**第三层：静心修炼**

在呼吸期，你找到一处僻静之地打坐冥想。不是每次冥想都有顿悟——但当条件成熟时，你会进入一段内心世界的旅程，回顾自己的选择和经历，在平静中获得领悟。

这条路径让"强大"不只来自战斗，也来自**内省与修行**——对应武侠中"闭关修炼"的传统。

**支柱对齐：**
- **Pillar 2**（每个选择有重量）— "凝神 vs 稳妥"是有风险有收益的真实抉择
- **Pillar 3**（战斗是高手过招）— 绝境顿悟强化了"一招定生死"的叙事张力

## Detailed Design

### Core Rules

**1. 顿悟事件表结构**

每个可触发的顿悟定义为一条配置记录：

```yaml
epiphany:
  id: "ep_desperation_sword_ch1"
  type: combat | narrative | meditation
  chapter_range: [1, 2]
  trigger_conditions:
    # combat 类型专用
    combat:
      hp_threshold: 0.2          # HP ≤ 20% 时
      min_actor_actions: 5        # 战斗中至少已有 5 次自然行动完成
      consecutive_qi_disadvantage_hits: 0  # 连续被气机克制命中的次数（0=不要求）
    # narrative 类型专用
    narrative:
      script_node: "ch1_cliff_revelation"
    # meditation 类型专用
    meditation:
      required_flags: ["visited_waterfall_cave"]
      min_meditation_days: 3      # 累计冥想至少 3 天
  preconditions:
    - not_flag: "ep_desperation_sword_ch1_done"
    - chapter: 1
  priority: 70                    # 同时满足多个顿悟时，取最高
  rewards:
    attributes: { strength: +2, agility: +1 }
    unlock: "move_breaking_water_cold_light"  # 解锁招式
    narrative_option: null         # 或解锁叙事选项 id
  skip_reward:                    # 选择"稳妥取胜"时的奖励
    hp_restore: 50%              # 回复 50% 最大气血
    neixi_restore: 50%           # 回复 50% 最大内息
    clear_stagger: true          # 清除自身破绽
    next_crit: true              # 下一击必暴击
    damage_taken_reduction: 30%  # 短时减伤，帮助稳住局面
  演出_key: "epiphany_sword_ch1"
  chapter_cap_cost: 1             # 占用章节配额
```

**2. 三种触发路径**

| 路径 | 触发场景 | 判定方式 | 玩家选择 |
|------|---------|---------|---------|
| **战斗绝境** | 战斗中 HP / 已完成自然行动数 / 连续被气机克制命中达到阈值 | 每次 `ActorTurnEnded` 或关键受击结算后检查；满足条件时概率触发（基础概率 + 绝境加深加成） | "凝神顿悟" vs "稳妥取胜" |
| **叙事脚本** | 主线/支线特定叙事节点 | 由叙事系统直接调用 `TriggerNarrativeEpiphany(node_id)` | 无选择——自然融入剧情 |
| **呼吸期冥想** | 在特定地点执行冥想行为 | 检查累计冥想天数 + 前置 flag；满足时确定触发 | 无选择——冥想成功即进入 |

**3. 战斗绝境概率机制**

战斗中顿悟不是 100% 触发。每次自然行动结束或关键受击结算后：

```
if 满足 combat.trigger_conditions:
  base_chance = epiphany_base_chance (默认 30%)
  desperation_bonus = (1 - current_hp_ratio) × desperation_scaling (默认 40%)
  final_chance = min(base_chance + desperation_bonus, chance_cap)
  roll → if success: 呈现抉择窗口
```

- HP 越低，触发概率越高（濒死奖励）
- 同一场战斗中只触发一次顿悟机会
- 若本次检查未触发，下次自然行动结束或关键受击结算后继续检查（条件仍满足的前提下）

**4. 凝神顿悟 vs 稳妥取胜**

选择"凝神顿悟"：
- 角色进入 `凝神` 状态，默认持续 3 个自然行动轮（即该角色接下来 3 次进入 `ActorTurnStarted` 时均不可行动）
- 凝神期间不能移动、出招、使用道具、切换内功、调息或使用轻功
- 凝神期间不发放奖励，也不刷新冷却；角色仍会承受敌人攻击和负面状态
- 凝神完成时才进入顿悟演出，发放永久奖励（属性 + 解锁），并刷新该角色所有普通招式、内功主动和轻功主动的冷却
- 完成后角色获得"悟后状态"buff（本战剩余时间全属性 +10%）
- 普通战斗中的凝神**没有默认免死保护**；教学或脚本战斗可通过配置单独开启保护

选择"稳妥取胜"：
- 立即获得 skip_reward（气血回复 + 内息回复 + 清除自身破绽 + 下一击必暴击 + 短时减伤）
- 立即回到正常战斗决策，不消耗本次主行动
- 不刷新冷却，不发放永久成长
- 本次顿悟机会消耗——但该顿悟事件**不标记完成**，未来仍可再次触发
- 每个顿悟事件最多被跳过 skip_limit 次（默认 3），超过后强制不再出现（避免无限刷）

**5. 章节门限系统**

| 章节 | 最大顿悟次数 | 说明 |
|------|------------|------|
| 序章 | 1 | 仅教学顿悟 |
| 第一章 | 3 | 战斗 1-2 + 叙事 1 |
| 第二章 | 4 | 战斗 2 + 叙事 1 + 冥想 1 |
| 第三章 | 5 | 全路径开放 |
| 终章 | 5 | 最终领悟 |

- 每次顿悟消耗 `chapter_cap_cost`（通常为 1）
- 达到上限后，战斗绝境不再触发概率检查；叙事脚本和冥想仍可在下一章补触发

**6. 顿悟奖励设计原则**

- **属性增长**：每次 +2~+4 点分配到 1-2 个基础属性（由事件配置固定，非玩家选择）
- **解锁内容**：三选一类型——
  - 新招式（约 60% 的顿悟）
  - 新叙事选项（约 25%，解锁特殊对话/行动路径）
  - 特殊能力（约 15%，如"一息三招"、"心眼"等被动）
- **境界联动**：如果顿悟后 total_power 跨越 realm_thresholds，自动触发角色属性系统的境界突破事件

**7. 冥想触发详则**

- 呼吸期中，特定场景点（瀑布、悬崖、古庙、湖心）可执行"静坐冥想"
- 冥想消耗半天体力（等同于赶路半天）
- 系统累计冥想天数；当满足某顿悟事件的 `min_meditation_days` 且前置 flag 齐备时，下次冥想确定触发
- 冥想顿悟不需要概率判定——条件满足 = 100% 触发

### States and Transitions

顿悟事件实例的生命周期：

```
locked → available → triggered → choosing → focusing → completed/skipped/failed
```

| 状态 | 含义 | 转移条件 |
|------|------|---------|
| locked | preconditions 未满足（章节/flag 不对） | preconditions 全部满足 → available |
| available | 条件满足，等待触发场景 | 场景条件满足 + 概率通过（或确定触发）→ triggered |
| triggered | 顿悟机会已出现 | 战斗场景：呈现抉择 → choosing；非战斗：直接 → completed |
| choosing | 玩家正在"凝神 vs 稳妥"界面 | 选择凝神 → focusing；选择稳妥 → skipped |
| focusing | 角色处于凝神状态，等待队友保护 | 撑过 epiphany_focus_turns → completed；HP ≤ 0 或被脚本打断 → failed |
| completed | 顿悟已完成，奖励已发放 | 终态，设置 `_done` flag |
| skipped | 玩家选择稳妥取胜 | skip_count +1；若 < skip_limit → 回退至 available；若 ≥ skip_limit → 终态 |
| failed | 凝神失败，奖励未发放 | 本战不再触发；战后回退至 available，不递增 skip_count |

### Interactions with Other Systems

| 系统 | 方向 | 接口 |
|------|------|------|
| **行气战棋战斗** | ← 监听 | `ActorTurnEnded` / `MoveResolved` 事件检查绝境条件；`OnDamageDealt` 更新 HP 状态；`OnEpiphanyTrigger` 通知战斗暂停 |
| **角色属性** | → 推送 | 发放属性增长 (`apply_permanent_modifier`)；触发境界突破检查 |
| **主线叙事** | ← 调用 | 叙事脚本节点直接调用 `TriggerNarrativeEpiphany(node_id)` |
| **武学组合** | → 推送 | 解锁新招式 (`unlock_move(move_id)`) |
| **心境双轴** | ← 查询 | 冥想顿悟的部分前置条件可查询心境区域 |
| **自然日+体力** | ← 监听 | 冥想消耗体力；累计冥想天数计数 |
| **朦胧化 UI** | → 推送 | 顿悟完成后推送"破境"文本事件（如果触发境界突破） |
| **存档系统** | ↔ 双向 | 保存：每个顿悟事件的状态、skip_count、章节已用配额、累计冥想天数 |

## Formulas

### F-1: 战斗顿悟触发概率 (combat_epiphany_chance)

| 变量 | 定义 | 取值范围 | 默认值 |
|------|------|---------|--------|
| base_chance | 基础触发概率 | 0-1 | 0.30 |
| current_hp_ratio | 当前 HP / 最大 HP | 0-1 | — |
| desperation_scaling | 绝境加深系数 | 0-1 | 0.40 |
| chance_cap | 概率上限 | 0-1 | 0.70 |

**表达式：**

```
desperation_bonus = (1 - current_hp_ratio) × desperation_scaling
final_chance = min(base_chance + desperation_bonus, chance_cap)
```

**输出范围：** [0.30, 0.70]

| HP 状态 | current_hp_ratio | final_chance |
|--------|-----------------|-------------|
| 20% HP | 0.20 | min(0.30 + 0.80×0.40, 0.70) = 0.62 |
| 10% HP | 0.10 | min(0.30 + 0.90×0.40, 0.70) = 0.66 |
| 5% HP | 0.05 | min(0.30 + 0.95×0.40, 0.70) = 0.68 |
| 1% HP | 0.01 | min(0.30 + 0.99×0.40, 0.70) = 0.70 (cap) |

### F-2: 悟后状态 buff (post_epiphany_buff)

| 变量 | 定义 | 默认值 |
|------|------|--------|
| all_attributes | 全部五维属性 | — |
| buff_multiplier | 增益倍率 | 1.10 |

**表达式：**

```
buffed_attribute = base_attribute × buff_multiplier
```

**持续时间：** 当前战斗剩余时间

## Edge Cases

### E-1: 凝神顿悟时被击杀

**场景：** 角色选择凝神后进入 3 个自身自然行动轮不可行动状态，期间被敌方攻击打至 HP ≤ 0。
**处理：** 普通战斗中凝神不会提供默认免死保护；该角色按正常落败/倒地规则处理，顿悟失败，奖励不发放，冷却不刷新。教学战斗、主线脚本战斗或特定顿悟事件可显式配置 `death_protection: true`，但这属于内容特例，不能作为通用规则。

### E-2: 同一场战斗满足多个顿悟事件条件

**场景：** 两个不同的 combat 类型顿悟事件同时 available。
**处理：** 取 priority 最高的一个呈现。未呈现的保持 available 状态供后续战斗触发。

### E-3: 章节配额耗尽后叙事脚本触发顿悟

**场景：** 章节已用完顿悟配额，但主线到达预设的叙事顿悟节点。
**处理：** 叙事顿悟不受章节配额限制（叙事优先原则）。配额仅约束战斗绝境路径。

### E-4: 冥想天数跨章节累计

**场景：** 玩家在第一章冥想 2 天，第二章冥想 1 天，某事件要求 min_meditation_days=3。
**处理：** 冥想天数全局累计，不按章节重置。

### E-5: 战斗中 HP 回复后不再满足绝境条件

**场景：** 顿悟检查时 HP ≤ 20%，但玩家在下次自然行动窗口使用调息恢复了 HP。
**处理：** 每次自然行动结束或关键受击结算后重新检查。HP 回升后条件不满足，不触发概率检查。已呈现的抉择窗口不受影响（一旦出现就不收回）。

### E-6: 跳过次数达到 skip_limit

**场景：** 玩家对同一顿悟事件连续选择"稳妥取胜" 3 次。
**处理：** 该事件进入终态，永不再出现。其属性/解锁奖励视为"错过内容"——不影响通关，但错失成长。

### E-7: 顿悟使功力值恰好跨越境界阈值

**场景：** 顿悟给 +3 力量，使 total_power 从 113 跳到 116，跨越 115 阈值。
**处理：** 顿悟演出完毕后，紧接播放境界突破演出（串联而非并行）。两个演出之间有 0.5 秒过渡。

### E-8: 序章教学顿悟被跳过

**场景：** 新玩家在序章选择了"稳妥取胜"。
**处理：** 序章教学顿悟的 skip_limit = 1（不允许反复跳过）。如果玩家跳过，在序章结束前的下一次战斗中强制重新触发（100% 概率，无抉择窗口，直接进入教学演出）。

## Tuning Knobs

| 参数名 | 默认值 | 范围 | 影响 |
|--------|--------|------|------|
| epiphany_base_chance | 0.30 | 0.1-0.5 | 战斗绝境基础触发概率。过高→太容易触发失去稀有感 |
| desperation_scaling | 0.40 | 0.2-0.8 | HP 越低概率加成幅度。影响"绝境"感 |
| chance_cap | 0.70 | 0.5-0.9 | 概率上限。防止 100% 触发 |
| skip_limit | 3 | 1-5 | 同一顿悟事件最多被跳过次数 |
| chapter_caps | [1,3,4,5,5] | per chapter | 每章最大顿悟次数 |
| buff_multiplier | 1.10 | 1.05-1.25 | 悟后状态全属性加成倍率 |
| epiphany_focus_turns | 3 | 2-4 | 凝神持续的自然行动轮数。越高越需要队友保护，过高会让玩家不敢选择 |
| skip_neixi_restore | 0.50 | 0.3-0.8 | 稳妥取胜时内息回复比例 |
| skip_hp_restore | 0.50 | 0.3-0.8 | 稳妥取胜时气血回复比例 |
| skip_damage_reduction | 0.30 | 0.1-0.5 | 稳妥取胜后的短时减伤比例 |
| meditation_stamina_cost | 0.5 | 0.3-1.0 | 冥想消耗体力（天数单位） |
| attribute_gain_per_epiphany | [2, 4] | [1, 6] | 每次顿悟属性增长范围 |
| total_epiphanies_target | [12, 18] | [8, 24] | 整个游戏流程顿悟次数目标 |
| skip_chance_decay | 0.15 | 0.05-0.30 | 每次跳过后同事件再触发概率衰减比例 |
| meditation_epiphany_cap | 4 | 2-6 | 冥想顿悟整局上限次数 |

**调参建议：**
- base_chance 配合 hp_threshold 调整：如果 hp_threshold=0.3（更早触发检查），应降低 base_chance
- 若 playtest 中玩家普遍选择"稳妥取胜"，提高 buff_multiplier 或降低 epiphany_focus_turns
- 若 playtest 中玩家普遍选择"凝神顿悟"，提高 epiphany_focus_turns 或增强稳妥取胜的即时生存收益
- 章节 caps 应与每章 boss 数量对齐（boss 战是战斗绝境的主要来源）

**风险-收益平衡约束（W14+W15）：**

为防止"稳妥取胜永远更优"（W14）和"理性玩家永远选冥想"（W15），设定以下结构性差异化：

**路径收益分层（高→低）：**

| 路径 | 属性增长 | 招式解锁 | 悟后buff | 附加收益 |
|------|---------|---------|---------|---------|
| 战斗绝境·凝神 | +3~4 | ✅ 可解锁战斗招式 | ✅ 全属性×1.1 本战剩余 + 完成后刷新技能冷却 | 叙事成就"绝境生慧" |
| 叙事脚本 | +2~3 | ✅ 可解锁叙事技能 | ❌ | 叙事选项解锁 |
| 呼吸期冥想 | +2（固定） | ❌ 不解锁招式 | ❌ | 心境轴 resolve+1 |

> **设计意图**：战斗凝神风险最高（HP≤20% + 3 个自身自然行动轮不能行动且无默认免死），因此收益最丰厚。冥想零风险零抉择，因此只给最基础的属性增长——它是"稳健积累"路径，不是"最优路径"。

**稳妥取胜的机会衰减（W14 核心修复）：**

选择"稳妥取胜"不是无代价的"留到下次"：

```
on_skip(epiphany_event):
    skip_count += 1
    # 同一事件再次触发时，base_chance 降低
    event.adjusted_chance = epiphany_base_chance × (1 - skip_count × skip_chance_decay)
    # skip_chance_decay 默认 0.15 → 跳过1次后概率降30%→15%→再次变得稀有
    if skip_count >= skip_limit:
        event.state = EXHAUSTED  # 永久不再出现
```

| 跳过次数 | 再次触发概率（基于 base_chance=30%） | 风险 |
|---------|--------------------------------------|------|
| 0 | 30% | — |
| 1 | 25.5%（×0.85） | 轻微衰减 |
| 2 | 21%（×0.70） | 明显衰减 |
| 3 | EXHAUSTED | 永久失去 |

> **设计意图**：稳妥取胜是"现在安全但未来更难遇到同一顿悟"。这使得凝神不再是"傻瓜选择"——如果你相信自己能撑过这段行气窗口，凝神的即时回报（永久成长 + 悟后buff）远超稳妥的短期收益。

**冥想路径约束（W15 核心修复）：**

| 约束 | 值 | 说明 |
|------|---|------|
| 冥想顿悟总次数上限 | `meditation_epiphany_cap = 4` | 整个游戏最多 4 次冥想顿悟 |
| 冥想不解锁高阶境界 | 境界 ≥ "炉火纯青" 的突破必须来自战斗/叙事顿悟 | 高境界要求实战证明 |
| 冥想前置条件更严格 | 每次冥想顿悟需要不同的"静心地点"（全游戏 4 处，分布在不同章节区域） | 不可反复在同一地点刷 |
| 冥想与战斗顿悟互不替代 | 部分顿悟事件标记 `combat_only: true`（解锁关键招式的顿悟只在战斗中出现） | 保证战斗路径的独特价值 |

> **结论**：冥想是"保底路径"（确保非战斗型玩家也能成长），但永远无法替代战斗绝境的丰厚回报。选择冥想 = 放弃招式解锁和高阶境界推进。

## Visual/Audio Requirements

**顿悟触发提示：**
- 屏幕边缘出现墨色涟漪波纹（从角色中心向外扩散）
- 低频钟声（一声）+ 环境音量降低 50%
- 持续 1.5 秒后呈现抉择 UI

**凝神顿悟演出：**
- 选择凝神时，角色进入打坐/收摄心神姿态，脚下持续出现微弱墨色涟漪，提示队友需要保护
- 凝神期间角色头顶显示剩余自然行动轮数，但不显示具体奖励数值
- 凝神完成后，战斗场景渐暗，仅角色高亮
- 闪回画面（2-3 帧关键记忆片段，来自此前的叙事选择）
- 墨色粒子向角色汇聚 → 爆散
- 新招式/能力名称以书法字体短暂显现
- 总时长 3-5 秒
- 音频：内息流动声 → 水滴入潭声 → 爆发音效

**稳妥取胜反馈：**
- 角色微光闪烁（恢复效果）
- 简短音效（内息回涌声）
- 无演出暂停，0.5 秒内完成

**冥想顿悟演出：**
- 场景光线渐柔，角色进入打坐姿态
- 内心世界背景（水墨风格的抽象空间）
- 与战斗顿悟共用奖励展示部分
- 总时长 5-8 秒（比战斗版略长，氛围更沉静）

## UI Requirements

**战斗抉择 UI（凝神 vs 稳妥）：**
- 全屏半透明遮罩（战斗暂停状态）
- 左右双选项布局：
  - 左："凝神顿悟"——图标（莲花/漩涡）+ 一行描述"3 次自身自然行动不能行动，若撑过可得永久突破"
  - 右："稳妥取胜"——图标（盾/气）+ 一行描述"立即回气回血，稳住此战"
- 无倒计时；玩家可查看敌方当前气机、行动队列、可见 tell 和队友站位后再决定
- 朦胧化原则：不显示具体概率、属性数值或解锁内容预览

**奖励展示 UI：**
- 顿悟演出结束后，中央展示获得内容（1-2 秒）：
  - 属性增长："力量 +2"（简洁数字）
  - 解锁内容：招式名称/能力名称 + 一句描述
- 若触发境界突破，追加境界名称大字展示

**冥想交互 UI：**
- 场景交互点提示："此处可静坐冥想"
- 确认消耗体力后进入冥想
- 朦胧化原则：不提示"是否有顿悟等待"——玩家只知道冥想可能有收获

**调试 UI（Debug 模式）：**
- 显示所有顿悟事件状态列表
- 每场战斗实时显示 final_chance 和 roll 结果

## Acceptance Criteria

### AC-1: 战斗绝境触发
- [ ] HP ≤ hp_threshold 且 actor_actions_completed ≥ min_actor_actions 时，每次自然行动结束或关键受击结算后执行概率检查
- [ ] 概率随 HP 降低而升高，不超过 chance_cap
- [ ] 同一场战斗最多触发一次顿悟机会

### AC-2: 抉择机制
- [ ] 选择"凝神顿悟"后角色进入 `凝神` 状态，持续 epiphany_focus_turns 个自然行动轮
- [ ] 凝神期间该角色不能移动、出招、用道具、切换内功、调息或使用轻功
- [ ] 凝神完成后才发放永久奖励、悟后 buff，并刷新该角色普通招式、内功主动和轻功主动冷却
- [ ] 选择"稳妥取胜"后立即获得 skip_reward，并回到正常战斗决策
- [ ] 抉择界面无倒计时，敌方当前气机、行动队列和可见 tell 仍可见

### AC-3: 奖励发放
- [ ] 属性增长正确应用到角色属性系统（永久修改器）
- [ ] 解锁内容（招式/叙事选项/能力）正确注册到对应系统
- [ ] 境界突破在属性变化后正确联动
- [ ] 凝神未完成时不发放奖励、不刷新冷却

### AC-4: 章节门限
- [ ] 每章顿悟次数不超过 chapter_caps 配置值
- [ ] 达到上限后战斗绝境检查停止
- [ ] 叙事顿悟不受章节配额限制

### AC-5: 叙事脚本触发
- [ ] `TriggerNarrativeEpiphany(node_id)` 正确匹配事件并执行
- [ ] 无抉择窗口，直接进入演出和奖励发放

### AC-6: 冥想触发
- [ ] 冥想天数全局累计
- [ ] 满足 min_meditation_days + required_flags 时下次冥想 100% 触发
- [ ] 冥想正确消耗体力

### AC-7: 跳过机制
- [ ] skip_count 正确递增
- [ ] 达到 skip_limit 后事件不再出现
- [ ] 未达 skip_limit 的事件回退至 available

### AC-8: 凝神失败与脚本保护
- [ ] 普通战斗中，凝神期间 HP ≤ 0 按正常落败/倒地处理，顿悟失败
- [ ] death_protection=true 的教学或脚本顿悟可覆盖默认规则
- [ ] 凝神失败不会设置 `_done` flag，也不会消耗章节顿悟配额

### AC-9: 存档完整性
- [ ] 保存/加载后所有顿悟状态、skip_count、章节配额、冥想天数正确恢复
