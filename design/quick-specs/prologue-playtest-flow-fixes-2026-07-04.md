# Quick Design Spec: 序章试玩流程修正

**Type**: Addition / Tweak  
**System**: 主线叙事、对话 UI、地图/场景管理  
**GDD Reference**: `design/gdd/main-narrative.md`, `design/gdd/dialogue-system.md`  
**Date**: 2026-07-04

## Change Summary

根据序章试玩反馈，修正当前实现中偏离“一日一夜”序章设计的流程与 UI 问题：对话必须显示说话者名字，序章不触发心境教学，日夜不可手动切换，后山崖洞按“取酒→无意回忆→雨夜留宿→草席回忆→睡到天亮”推进，山庄日常跑腿应变为真实子任务而非选项即完成。

## Motivation

当前试玩暴露的问题会削弱序章核心体验：玩家无法辨认 NPC 说话者、山洞过早暴露所有可交互物、心境教学提前污染序章、手动日夜切换破坏叙事时序、山庄跑腿缺少真实行动。修正后，序章应更接近“一日一夜设计”中的情绪曲线。

## Design Delta

Current GDD says (`docs/superpowers/specs/2026-06-29-prologue-a-day-and-night-design.md`, P00-07):

> 主角入夜后抵达崖洞。崖洞不是藏宝室、矿洞或阴谋地点，而是主角和师姐共享过的小秘密基地。所有互动点都服务于回忆。

This spec changes implementation behavior to:

1. 崖洞首次进入时只允许取寿酒，不展示其他可交互物。
2. 取得寿酒后无意瞟见壁画，触发占位回忆过场；过场结束后切换夜间。
3. 玩家首次靠近洞口三格内时触发雨夜旁白，解释不得不留宿。
4. 雨夜旁白后才开启崖洞其他可交互物，但洞口仍不可离开。
5. 首次交互草席触发师姐回忆过场；之后再交互草席才出现“睡到天亮 / 再转转”的选择。
6. 睡到天亮后才记录 `prologue_cave_overnight`，开放返回山庄的灭门段。

## New Rules / Values

- 对话 UI：有 `speaker` 的节点必须显示名称；没有立绘时只隐藏立绘图，不隐藏名字。
- 序章禁用手动日夜切换；日夜变化仅由剧情 flag 驱动。
- 后山小路动物足迹在日间流程可见，不需要切换夜晚。
- 山庄日常跑腿是三项子任务：厨房送药草、药房分拣药包、练武场传话。接到跑腿后 HUD 展示子任务，完成一个划掉一个。
- 选择“先去哪边帮忙”只记录接取跑腿，不直接完成跑腿。
- 灭门搜证必须防止玩家重复选择已完成调查项导致卡住；完成必要线索后允许总结推进。

## Affected Systems

| System | Impact | Action Required |
|---|---|---|
| 对话系统 | UI 字号、名字显示、部分对话事件调整 | 修改 Godot 面板与 YAML |
| 主线叙事 | 序章跑腿、山洞、灭门段推进顺序 | 修改场景脚本与内容 flag |
| 地图/场景管理 | 禁用手动日夜切换 | 修改 `SceneGameBase` 输入与提示 |
| 轻量任务 HUD | 临时支持三项子任务展示 | 复用 `TrackedQuestKind.Side` |

## Acceptance Criteria

- [ ] 所有带 `speaker` 的对话节点在无立绘时仍显示角色名。
- [ ] 对话正文字号与选项字号增大，名字与立绘/占位区距离更紧。
- [ ] 序章按键提示不再出现“切换日夜”，按 N 不切换日夜。
- [ ] 后山小路动物足迹在白天可直接查看。
- [ ] 后山崖洞首次进入只展示取酒入口；取酒后触发壁画回忆占位过场并切夜。
- [ ] 靠近洞口三格触发雨夜留宿旁白，之后开放洞内其他交互但不能离洞。
- [ ] 草席首次交互触发师姐回忆占位过场；再次交互才可选择睡到天亮。
- [ ] 灭门搜证不会卡在四/五个选项循环里，完成关键线索后可推进。
- [ ] 山庄跑腿接取后展示三项子任务，玩家需到对应地点或 NPC 完成。
- [ ] 序章山洞回忆不触发心境位移或心境教学。
